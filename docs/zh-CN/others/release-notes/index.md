## 2026-10-28

### 发布内容

#### 重点更新

- 【功能】完善账号安全与租户治理，覆盖密码设置与找回、令牌和密钥安全、访问来源控制、租户禁用、语言偏好、租户初始化补偿和多语言协议发布。
- 【功能】完善成员、角色与消费额度治理，支持批量角色和额度维护、权限包核查、模型权限申请审批及用量审计。
- 【功能】重构账务与结算链路，统一账户准备、Credit 发放回收、消费账期、最终用量扣减、尾差对账和模型提供方收益。
- 【功能】升级模型服务供给与调用接入，覆盖模型生命周期、来源与接入点、凭据、连通性检测、计费方式、多媒体协议和聚合路由。
- 【功能】补齐模型调用观测与排障能力，支持多角色数据隔离、TPOT 指标、趋势分析、请求与上游尝试区分、异步数据和成员项目筛选。
- 【功能】建设通知中心与业务审计，覆盖通知偏好、租户联系人、维护和注册通知、财务及模型状态通知、业务操作日志和实时重连补推。
- 【功能】增强云上部署与多云接入，支持专属资源池授权、部署预检、运行资产迁移、云账号健康检测、批量授权和快速部署引导。
- 【功能】完善私有部署与集群运行，覆盖部署候选、实例 API 配置、健康检查、集群接入、终端票据、自有模型、显存测算、作业终端和资源预留。
- 【功能】完善镜像、对象存储与资源计量，支持镜像预检、多云 S3 存储源、容量管理、分片续传、运行中挂载、费用重算、规格定价和个人用量。
- 【界面】优化公共界面与运行支持，升级图表组件、弹窗和设置页交互，增强消息与任务恢复兼容，并清理已停用的旧入口。

#### 账号与租户

- 【功能】统一首次设密、改密和邮箱找回流程；首次设密无需提供旧密码，首次设密后保留当前会话，普通改密和找回密码后撤销相关网页会话。
- 【功能】重构令牌签发、密钥校验和前端会话处理，区分网络错误、权限错误、凭据失效、来源策略拒绝和登录失效等状态。
- 【功能】支持租户管理允许的访问来源地址，个人和项目模型调用密钥支持来源地址白名单；密钥新建与轮换结果分别展示，关闭后清理复制状态。
- 【功能】增加租户退役预检查、不可恢复禁用和资金受理拦截，停用关联会话与业务密钥，并保护禁用过程中的身份和资金操作。
- 【界面】统一租户公开名称及跨页面展示，账号切换列表优先显示用户名；平台和个人语言偏好分别保存，补充拉美西班牙语页面及服务端文案。
- 【质量】完善新租户创建消息的独立消费、重试和初始化补偿，补齐默认模型调用密钥的额度、名称和描述；支持中文、英文和拉美西班牙语系统协议按版本同步发布，并兼容旧协议。

#### 成员、角色与消费额度

- 【功能】支持成员角色变更预览、批量执行、按角色查看成员及结果核对；统一角色可见和可分配范围，角色使用查询支持分页、全局排序和跨页稳定顺序。
- 【功能】增加权限包预览、变更明细、未绑定权限和引用关系核查，收敛菜单授权边界；导入时清理历史用户直授菜单权限，并防止并发导入覆盖。
- 【功能】支持成员额度、周期策略和模型访问范围的批量维护，提供选人、预览、分块提交、冲突识别和回执回读；无效项不会写入整批结果。
- 【功能】统一单成员额度、使用策略和模型白名单维护入口，补充额度单位换算、快捷填充、阈值提示、额度预警和每日模型用量展示。
- 【功能】支持成员从模型广场和体验中心申请、查看和取消模型访问权限，管理员可审批、拒绝并追踪申请状态。
- 【功能】完善用量详情、按日成员汇总和当前日查询，支持按姓名、标签、成员、项目和模型筛选，并可补齐近 90 天缺失的历史汇总。

#### 账务与模型提供方结算

- 【功能】增加轻量账户准备能力，缺失账户可幂等补建；账户余额、余额可见性和充值能力独立处理，收敛旧聚合账户概览接口。
- 【功能】将 Credit 发放和回收明确为独立业务动作，记录申请标识和原因、校验重复请求，并区分受理中与已入账状态。
- 【功能】统一客户消费账期、消费来源和日趋势口径，按明确账期生成客户财务概览和来源统计；月度账单重建前先对齐 ModelOne 日汇总。
- 【功能】将普通用量与可结算尾差纳入同一模型提供方结算流程，生成前检查缺失或重复明细，并处理低于最小物化金额的待决尾差。
- 【功能】ModelOne 按实际最终用量推进额度扣减和账务入账，区分供应方结果、扣减和入账状态；异步媒体任务完成实际用量后再结算。
- 【功能】增加按账期和模型提供方查看尾差、归因缺失、收益和账务差异的对账信息，并补充近期结算及累计 Credit 收益概览。

#### 模型服务与调用接入

- 【功能】模型发布流程切换为 V2 修订和运行时快照，统一当前版本与待审核版本的查询、发布和审核；支持预约更新、强制下架、路由缓存刷新及符合条件的模型删除。
- 【功能】增加模型来源、接入点和协议目录，收敛协议请求头、接入点编辑和候选过滤，并兼容旧来源向接入点迁移。
- 【功能】完善凭据查询、绑定、引用模型和审计；凭据新建与轮换时加密保存、脱敏展示，并可在操作前检查受影响模型。
- 【功能】增加配置驱动的模型连通性探测和候选凭据测试，返回供应方错误、凭据错误类型及检测结果，并完善提交中的关闭保护。
- 【功能】新建模型发布不再提供免费计费方式，存量模型和草稿保持原规则兼容，并补充同步与异步最终用量说明。
- 【功能】按调用主体的租户、个人和项目授权过滤模型列表，区分余额、成员或项目额度、密钥额度和模型权限导致的调用拒绝。
- 【功能】适配图片和视频多媒体协议、嵌套及数组用量字段、输入输出和缓存计量；参数修正按协议和元模型匹配，配置异常时明确返回解析失败。
- 【界面】升级体验中心图片和视频调用、异步任务查询、结果展示、音频播放、拖动和下载；接口说明和示例按所选协议展示请求参数，并在切换或离开时保护会话草稿。
- 【功能】发布和编辑图片、视频模型时按协议约束计量单位和调用方式，调整视频价格预览和单位展示；模型详情增加近 24 小时成功率、服务状态和趋势信息。
- 【性能】聚合模型按请求能力、授权、并发和上游健康状态筛选候选并执行失败重试；流式调用记录超时、断开、重试和每次尝试阶段，保留客户端来源。
- 【功能】平台设置支持选择对象存储或本地存储，维护模型媒体上传的存储桶、接入地址、对象路径前缀和凭据，并支持运行时更新。

#### 模型调用观测与排障

- 【功能】按运营、模型提供方、组织管理员和成员的授权范围提供观测视角，支持按来源、能力模型、客户、客户端和实际路由模型分析，并隔离组织内部数据。
- 【功能】补齐 TPOT、分布、排序、日趋势和小时查询，可从请求极值进入明细，并支持按配置恢复历史观测数据。
- 【功能】区分用户请求和上游尝试，兼容历史异步调用；按图片张数、时长、字符或 Token 展示用量，并在列表和详情中区分请求模型与实际处理模型。
- 【功能】模型用量明细支持成员、项目和模型筛选，详情跳转保留筛选和时间范围，缺少对象编号时阻止误跳转。

#### 通知中心与业务审计

- 【功能】支持个人按通知类型维护邮件偏好和查看站内消息，租户管理员可维护通用联系人及接收渠道，并预览通知模板。
- 【功能】统一维护通知和注册事件通知，补充多语言消息详情、投递状态、失败处理和遗漏投递补偿；按实际发送结果更新批次状态，避免重复发送。
- 【功能】将余额、额度、预算、模型预约下架和平台许可证到期提醒接入统一通知，并补充中文、英文和拉美西班牙语模板。
- 【功能】建立业务操作记录，覆盖登录、成员角色、权限、财务、资源池、模型治理和凭据生命周期；支持按作用域和操作人筛选、脱敏导出和留存设置。
- 【功能】支持多标签页实时提醒、未读数量、连接协调和断线重连补推，并限制用户和节点的实时连接数量，清理无效连接。

#### 云上部署与多云接入

- 【功能】支持专属资源池客户授权、规格配额分页、硬件摘要和批量追加；部署使用客户已授权网络，并补充授权审计和名称配置。
- 【功能】增加云上部署预检和进度查询，检查账号、许可证、云资源、规格以及模型和框架依赖，并在提交部署时再次拦截不满足条件的请求。
- 【功能】完善多云参考方案、规格显存展示和部署点候选规格配置，适配华为自定义 OBS 模型、云推理访问和符合条件的非流式在线调试。
- 【功能】支持通过 ZIP 包迁移模型运行资产、框架版本、云平台和资源池，提供映射预检、任务记录和结果查看，并收敛旧导入导出入口。
- 【功能】支持批量刷新云账号健康状态，区分身份、配置和服务可达性问题，并展示云商返回的错误原因和处理提示。
- 【功能】支持云平台、账号、地域和授权配置进度展示，以及租户云平台批量授权、地域覆盖和授权资源候选；运行中部署时不能停用云平台。
- 【功能】模型商店支持按公共或专属资源池查找模型；快速部署按模型、框架、策略和推荐方案引导选择，部署进度展示云平台事件，监控支持按地域和时间范围查询。

#### 私有部署与集群运行

- 【功能】完善自有模型和推理模板的框架、规格、依赖制品及地域候选，补充配置问题和处理提示。
- 【功能】保存实例 API 端口和协议快照，模板批量实例拆分为独立任务，按配置端口管理 vLLM 监控，并同步实例删除和作业终态。
- 【功能】支持框架和实例自定义健康检查、发布前真实推理验证及失败后重检，区分作业运行状态和模型可访问状态。
- 【功能】提供地域工作台和集群注册向导，支持连接配置文件解析、连通性和地址检查；补齐加速卡指标诊断及按地域、集群和节点查看监控。
- 【功能】终端、作业日志和模型下载日志改用短时资源绑定票据，支持终端尺寸同步、无 bash 镜像的 sh 回退、集群执行和文件日志连接；增加访问代理配置、链路测试和代理重启。
- 【功能】支持自有模型选择推理框架和地域资源，提供自定义运行配置及启动命令；支持采集和维护 vLLM 运行档案、显存测算及档案导入导出。
- 【界面】作业终端支持多窗格和新标签页，作业日志支持关键词、大小写和上下文筛选，并可保留阅读位置、暂停或继续刷新。
- 【功能】集群工作台增加调度限制、节点资源预留和部署资源预览，支持按集群、集群资源、节点和节点资源配置调度策略；预览不占用实际资源。
- 【功能】在线开发、作业和模型部署支持项目归属、项目筛选及资源规格筛选排序；清理 Codelab、Gitea 和旧模型训练、实例作业、快速部署与微调链路。

#### 镜像、对象存储与资源计量

- 【功能】支持 Harbor 和云 Registry 组件登记、分阶段预检、健康检查、资产同步、版本配置复制、批量启用及临时 Docker 登录；镜像组和 tag 支持用量与额度管理。
- 【界面】重排公共和自定义镜像仓库、项目列表及详情分栏，集中展示数量、配额、时间、版本操作和上传指引。
- 【功能】支持多云 S3 存储源发现、凭据保护、权限预检、地域绑定和连接状态检查；同一存储源可关联多个地域，并可维护桶数量、容量和价格。
- 【功能】增加对象容量账本、写入预留、初始化和校准，支持存量桶迁移、项目关联、容量不足处理和余额恢复后的待清理状态恢复。
- 【功能】支持最大 50 GiB 文件的分片创建、恢复、查询、上传、完成、取消、断点续传和失败重试，并沿用服务端分片大小。
- 【功能】支持作业运行中动态挂载和卸载 S3，补充 CSI 证书处理、挂载状态检查和模型提供方标识，区分请求受理与实际可用。
- 【功能】将 Bucket 按容量和价格纳入资源计量与 Credit 扣减，支持按小时、日、月重建费用并追加差额，导出补齐作业、Bucket、地域和可用区信息。
- 【功能】增加规格定价统计、指标价格维护和客户规格额度批量调整，支持规格批量调价与启停；统一内存额度为 GiB，并支持查询资源配额和个人用量。

#### 公共界面与运行支持

- 【质量】完善空队列、生产者探测、节点租约失效和服务异常退出保护，恢复服务重启后的消息监听、定时任务和限时占用检查；兼容历史平台许可证导入。
- 【界面】显卡使用率图表升级到 ECharts 6，清理页面销毁后的监听，按当前语言显示数值；统一公共弹窗关闭与提交保护，并按权限展示设置页可编辑或只读状态。
- 【界面】优化导航文字裁切、页面返回、表格操作列和多语言长文案展示，改善不同语言下的公共交互体验。
- 【质量】清理旧应用、分享、聊天会话、文档处理和废弃模型调用入口，移除部分旧私有部署代理入口，保留云上部署仍在使用的集成路径。

## 2026-06-30

- 【功能】新增并完善用户空间能力，支持工作区概览、项目管理、个人 / 项目 Model API Key、成员额度、额度申请、操作记录、预算和模型白名单等自助管理能力。
- 【功能】强化 API Key 与 Quota 管理链路，支持个人 Key / 项目 Key 归因、网关认证、配额日志、过期时间、限额统计，并优化异常场景下的额度扣减准确性。
- 【功能】模型服务能力持续升级，支持缓存计费、阶梯计费、Web Search 计费，以及图片、视频、语音等多模态模型的用量解析和扣费处理。
- 【功能】体验中心文本、图片、视频、语音页面完成结构升级，优化模型选择、参数配置、模型对比、文件上传、Key 选择和新旧版切换体验。
- 【功能】模型发布、模型市场、我的模型、元模型配置、模型来源和模型审核流程增强，提升模型上架、配置、审核、发布和多语言维护效率。
- 【功能】本地算力平台资源纳管能力升级，覆盖资源池、集群、加速卡、规格、镜像、存储、部署模板、显存计算、模型服务、运行实例和在线 IDE。
- 【功能】多云调度平台推荐部署和模型迁移能力增强，支持按模型、框架、部署模式、云商和策略生成推荐方案，并补充硬件规格、价格、库存和多云适配信息。
- 【功能】账务链路重构，覆盖账户概览、月度账单、账户流水、充值、模型供应方收益和运营管理员结算，并优化消费来源归因和 Stripe 落账可靠性。
