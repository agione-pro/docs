# 检查和维护 License 生命周期

本任务用于分别确认 Platform License 与 Managed Objects 状态，准备有效的 License 批次，并建立订阅、有效期、额度和导入记录巡检。

## 适用角色

- 平台运营方、License 管理员、资源运营人员

## 开始前准备

1. 确认当前环境、部署、注册码和目标授权区域。
2. 记录 Platform License 状态与授权版本，再记录 Managed Objects 有效期、总额度、已用和剩余额度。
3. 确认使用 Platform License 批量编辑器还是 Managed Objects 激活窗口，并准备相应审批。
4. 注册码、激活码和支付凭据不得出现在文档、截图或工单中。

## 操作流程

### 1. 检查当前 License 状态

进入[License 管理](../../../usermanual/billing/operator/license/license/)，先查看顶部总览，分别核对 Platform License 和 Managed Objects，并确认当前页面及注册码属于目标环境和目标部署。

### 2. 选择区域并准备 License

- Platform License：每个非空逻辑行粘贴一条 License，或导入 `.lic`、`.license`、`.txt` 文件；`自动换行` 和 `不换行` 仅用于检查显示。
- Managed Objects：选择目标 SKU，打开 `获取并激活 License`，使用 `我已有激活码`；购买入口不属于只读核查。
- 批次最多 100 条、单条最多 64 KiB、文件最多 1 MiB。系统整批校验，任意一条无效都会阻止整批发布。

提交前再次核对环境、部署、注册码、目标区域和 License 来源。未经明确批准，停在 `提交并激活` 或 `激活` 前。

### 3. 核对详情和授权构成

激活后刷新 License 管理页面。Platform License 核对订阅状态与授权版本；Managed Objects 核对导入记录、详情、授权构成、生效时间、到期时间、总额度和各类资源占用。

### 4. 建立有效期和额度巡检

定期检查剩余有效期、剩余额度和纳管对象变化。根据资源扩容计划设置内部预警时间；预计不足时提前准备续期或扩容，并评估现有实例和新建任务的影响。

## 完成检查

> **用途：** 以下检查确认 License 不仅被激活，而且在正确环境提供了可解释、可持续的授权容量。

| 检查项 | 通过标准 |
| --- | --- |
| 部署匹配 | 环境、部署、注册码、目标区域和激活材料一致。 |
| 状态有效 | Platform License 和 Managed Objects 状态分别完成核对。 |
| 批次有效 | 文件类型、条目数量、单条大小、文件大小和整批校验符合页面规则。 |
| 授权清晰 | 授权版本、有效期、额度、导入记录和授权构成可解释。 |
| 对象一致 | 纳管对象与实际资源和业务计划一致。 |
| 后续计划 | 到期、扩容和额度不足的责任人及处理时间明确。 |

## 常见失败分支

| 现象 | 优先检查 |
| --- | --- |
| 找不到激活入口或注册码 | 账号权限、授权区域、页面加载和实例状态 |
| 激活码无效 | 是否匹配当前注册码、授权类型、有效期及复制完整性 |
| License 批次无法提交 | 文件类型不支持、超过 100 条、单条超过 64 KiB、文件超过 1 MiB或存在无效条目 |
| 激活后状态未更新 | 页面缓存、同步延迟和当前授权区域 |
| 剩余额度异常 | 纳管对象、授权构成、历史占用和资源同步 |
| License 即将到期或不足 | 业务扩容计划、续期周期、受影响实例和审批进度 |
