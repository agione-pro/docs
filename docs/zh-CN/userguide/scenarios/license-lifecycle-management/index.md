# 场景概览 - License 生命周期管理

本场景帮助运营方区分 Platform License 与 Managed Objects 授权，执行正确的激活流程，并持续检查订阅状态、授权版本、有效期、额度和纳管对象。

## 适用角色

- 平台运营方、License 管理员、资源运营人员

## 场景目标

- 区分 Platform License 平台订阅与 Managed Objects SKU 授权。
- License 与目标环境、部署、注册码和授权类型一致。
- 激活后状态、有效期、总额度、已用和剩余额度可验证。
- 纳管对象与授权构成能够解释额度占用。
- 到期或容量不足前有明确续期、扩容和业务处理计划。

## 场景流程

**主线：** 确认部署与两类状态 -> 选择 Platform License 或 Managed Objects -> 校验 License 批次 -> 经审批激活 -> 核对记录与额度 -> 续期或扩容

| 阶段 | 核心结果 |
| --- | --- |
| 1. 识别当前状态 | 部署、注册码、Platform License 状态和 Managed Objects 状态明确 |
| 2. 选择并校验 | 目标区域、License 来源、批次限制和校验结果明确 |
| 3. 完成激活 | 激活方式和授权结果与目标部署匹配 |
| 4. 核对使用 | 授权版本、导入记录、纳管对象和额度占用可解释 |
| 5. 持续治理 | 到期、剩余额度和扩容计划持续可见 |

## 开始前准备

- 具备 `账务 > License > License` 页面权限。
- 已确认当前页面属于目标环境和目标部署。
- 已确认本次操作针对 Platform License 还是 Managed Objects SKU。
- 批量导入时准备不超过 100 条、单条不超过 64 KiB，且 `.lic`、`.license` 或 `.txt` 文件不超过 1 MiB。
- 激活、续期和扩容前已确认授权范围及业务影响。

## 推荐阅读顺序

1. 先查看 License 管理中的 Platform License 和 Managed Objects 状态。
2. 选择正确区域并核对注册码与 License 来源。
3. 激活前核对多行/文件导入限制和整批原子校验规则。
4. 激活后核对授权版本、导入记录、授权构成和纳管对象。
5. 建立到期与剩余额度巡检，提前安排续期或扩容。

## 完成检查

> **用途：** 以下检查是本场景的退出条件，用于确认 License 已在正确实例生效且可支撑预期资源规模，不以“激活按钮返回成功”作为唯一标准。

| 检查项 | 通过标准 |
| --- | --- |
| 1 | 环境、部署、注册码、目标区域和激活材料彼此匹配。 |
| 2 | Platform License 与 Managed Objects 状态分别完成核对。 |
| 3 | 批次数量、单条大小、文件类型和整批校验符合页面规则。 |
| 4 | 授权版本、有效期、额度、导入记录和纳管对象能够解释。 |
| 5 | 到期、扩容和剩余额度预警责任人及处理计划明确。 |
