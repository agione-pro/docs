# 场景概览 - 模型消费与收益

本场景介绍调用方如何核对用量明细，模型提供方如何核对客户调用和收益，以及双方如何按相同账期完成对账。

## 适用角色

- 平台用户、模型提供方

调用方提供核对范围及日志中的模型/请求标识；提供方补充对应的生效版本、计费单位与价格依据。仍无法解释的差异交给运营方，不互相转交真实密钥或完整请求正文。

## 场景目标

账期是用于统计核算的周期，日期用于缩小查看范围；Token 是模型处理的文本单元，不是金额。

- 按相同账期与日期查看用量；在调用日志核对模型路由、调用归属和来源。
- 收益数据能够回溯到有效调用和价格规则。
- 异常能够定位到模型 ID、调用归属、调用方、账期或计费配置。

## 场景流程

**主线：** 统一对账范围 → 核对调用日志 → 核对用量明细 → 核对消费与收益

| 阶段 | 核心结果 |
| --- | --- |
| 1. 统一范围 | 用户、模型、模型 ID、供应方、币种和时间范围一致 |
| 2. 核对调用 | 模型 ID、调用归属、成功、失败、Token 或时长记录可追溯 |
| 3. 核对用量 | 按账期和日期分别查看消耗概览与明细，不预设额外筛选器 |
| 4. 核对结算 | 分别核对用户消耗、提供方收益和生效价格，不直接等同 |

## 开始前准备

- 明确模型、模型 ID、时间范围、账期和计费单位。
- 准备脱敏后的请求时间或调用标识。

## 推荐阅读顺序

1. 查看调用日志
2. 查看用量明细
3. 提供方查看模型收益
4. 对照计费配置完成核对

## 完成检查

按下表确认结果；未通过时，返回对应操作页排查后再继续。

| 检查项 | 通过标准 |
| --- | --- |
| 1 | 同一时间范围内的成功和失败调用能够在日志中定位。 |
| 2 | 用量明细按账期和日期核对，调用路由和归属在日志中分别检查。 |
| 3 | 用户消耗与提供方收益分开读取，差异按统一范围和生效价格交接核对。 |
