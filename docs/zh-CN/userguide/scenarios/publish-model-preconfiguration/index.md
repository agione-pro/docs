# 场景概览 - 发布模型（预设置）

指导运营管理员在模型提供方发布公有模型前，完成平台侧的基础数据与审批配置。元模型定义能力，模型源代表上游服务来源，Endpoint 是来源下的接入点，模板把这些配置组合为发布预设。

## 适用角色

- 运营管理员

交接给模型提供方时，提供可选元模型、模型源 Code、Endpoint 和模板所属来源/地域，确认提供方能选到正确配置后再进入发布；真实凭据不放入共享交接材料。

## 场景目标

- 确认已有模型作者，准备元模型、模型源、Endpoint 和模板。
- 准备标签、计价口径和模型审核能力。
- 让模型提供方能够基于统一配置发布模型。

## 场景流程

**主线：** 定义标准模型 → 接入模型源 → 组合发布模板 → 验证提供方可用性

| 阶段 | 核心结果 |
| --- | --- |
| 1. 定义标准模型 | 作者、元模型、模态、能力和协议形成统一口径 |
| 2. 接入模型源 | 模型源 Code、Endpoint、Base URL 与协议已维护 |
| 3. 组合发布模板 | 作者、供应方、地域和元模型组合正确 |
| 4. 验证可用性 | 模型提供方发布时能看到正确选项，审核入口可用 |

## 开始前准备

- 已明确模型类型、输入输出模态和协议。
- 已准备上游模型 接口地址、地域和请求头规则。
- 已明确计费币种和审核责任人。

## 推荐阅读顺序

1. 元模型
2. 模型源
3. 模型模板
4. 标签、计价口径和模型审核

## 完成检查

按下表确认结果；未通过时，返回对应操作页排查后再继续。

| 检查项 | 通过标准 |
| --- | --- |
| 1 | 提供方能选择所需元模型、模型源和 Endpoint；模板列表中能定位对应预设。 |
| 2 | 模态、协议、Token 限制和高级能力配置一致。 |
| 3 | 标签和币种满足发布与计费需要。 |
| 4 | 模型审核入口和审批角色可用。 |

## 常见失败分支

| 现象 | 优先检查 |
| --- | --- |
| 模型提供方 看不到模板 | 模板状态、发布范围、元模型和模型源关联 |
| 模型源接入信息不完整 | 模型源与 Endpoint 是否分别保存、地址和协议是否匹配 |
| 计费配置无法完成 | 币种、计费单位、模型类型和价格规则 |
