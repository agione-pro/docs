# 场景概览 - 模型的体验与调用

指导用户发现模型、体验模型并完成 API（应用程序接口）调用。Playground 是在线体验中心，个人 Key 是当前账号用于调用认证的密钥。

## 适用角色

- 平台用户
- 查看客户调用结果的模型提供方

提供方向调用方交付可访问的模型/供应方标识、协议、价格与范围；调用方自行准备获授权密钥，完成体验和请求后按时间与模型核对自己的日志。需要提供方协查时，只交请求时间与标识等必要信息，不交真实密钥。

## 场景目标

- 在模型市场找到目标模型与供应方，确认价格、额度和访问权限。
- 在与模型模态对应的文本、图像、视频或语音 Playground 完成一次体验。
- 使用个人调用 Key 完成 API 调用并查看调用记录。

## 场景流程

**主线：** 发现模型并确认访问条件 → 在线体验 → API 接入 → 回看调用记录

| 阶段 | 核心结果 |
| --- | --- |
| 1. 发现模型 | 找到符合任务的模型、供应方及获授权的调用条件 |
| 2. 在线体验 | 使用无副作用输入验证模型能力和输出模态 |
| 3. API 接入 | 使用个人授权密钥完成一次受控请求 |
| 4. 回看记录 | 用户可定位自己的调用日志；提供方按权限核对客户调用 |

## 开始前准备

- 已完成登录并拥有目标模型的访问权限。
- 已准备个人调用 Key，且账户额度和模型配额可用。

## 推荐阅读顺序

1. 查看当前场景概览和准备条件
2. 按用户快速指引发现模型，并选择与模型模态一致的体验中心
3. 完成 API 调用
4. 查看调用记录并处理失败分支

## 完成检查

按下表确认结果；未通过时，返回对应操作页排查后再继续。

| 检查项 | 通过标准 |
| --- | --- |
| 1 | 用户能够在模型市场找到目标模型并查看能力、供应方和调用说明。 |
| 2 | Playground 请求成功，输入输出符合模型模态。 |
| 3 | API 请求使用个人授权密钥并获得成功响应。 |
| 4 | 我的调用中能找到对应时间和模型的调用记录。 |
| 5 | 提供方需要参与核对时，按其权限范围查看相同模型和时间范围的客户调用统计。 |

## 常见失败分支

| 现象 | 优先检查 |
| --- | --- |
| 找不到模型 | 模型状态、公有/私有范围、租户授权和筛选条件 |
| Playground 失败 | 输入模态、参数、模型状态和账户额度 |
| API 返回认证错误 | Personal Key、Header 格式和模型授权 |
| API 成功但调用记录为空 | 月份、模型、调用来源、名称/ID和结果分类 |
