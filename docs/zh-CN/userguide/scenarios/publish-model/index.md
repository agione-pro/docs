# 场景概览 - 发布模型

帮助模型提供方将上游模型发布为可体验、可调用、可审核的模型服务。元模型是模型能力档案，模型源代表上游来源，Endpoint 是该来源下的服务接入点。

## 适用角色

- 模型提供方
- 运营管理员，如涉及审批或预设置

运营管理员先交付可选的模型基础配置；模型提供方完成发布后，将模型标识、协议、价格与授权范围交给目标用户验证。需要审核时，先把目标模型和版本交运营管理员处理，不以提交成功代替审核或调用验证。

## 场景目标

用户完成本场景后，可以发布一个可体验、可调用、可审核的模型服务。

## 场景流程

**主线：** 准备发布条件 → 配置并测试模型 → 提交审核 → 上架并验证调用

| 阶段 | 核心结果 |
| --- | --- |
| 1. 准备发布条件 | 元模型、模型源、Endpoint 与凭证已确认 |
| 2. 配置并测试 | 模型信息、协议、计费和限流通过校验 |
| 3. 提交审核 | 需要审核的发布申请可定位状态和版本 |
| 4. 上架验证 | 目标用户能找到、体验并调用已发布模型 |

## 开始前准备

- 已完成模型发布预设置
- 已确认是否先部署算力服务；本发布场景使用已有上游服务，准备请求 URL、凭证、协议和上游模型名称
- 已确认计费和限流策略

## 完成检查

按下表确认结果；未通过时，返回对应操作页排查后再继续。

| 检查项 | 通过标准 |
| --- | --- |
| 1 | 协议测试通过，模型源和请求参数可用。 |
| 2 | 计费、限流、发布区域和发布时间符合计划。 |
| 3 | 需要审核时，提交后能核对对应状态和版本。 |
| 4 | 发布完成后，目标用户能找到、体验并调用模型。 |

## 常见失败分支

| 现象 | 优先检查 |
| --- | --- |
| 无法选择元模型或模型源 | 运营方预配置、状态和账号可见范围 |
| 协议测试失败 | 接口地址、请求头、模型源 ID、协议和返回解析 |
| 无法提交审核 | 必填项、计费、限流、发布区域和测试状态 |
| 发布后不可见 | 审批状态、发布时间、公有/私有范围和租户权限 |
