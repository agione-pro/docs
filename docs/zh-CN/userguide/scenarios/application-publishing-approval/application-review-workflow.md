# 应用发布与审核（旧流程已停用）

::: warning 不能继续按旧流程操作
当前用户手册已移除应用列表与应用审核页面。本页不再描述应用发布、审核或客户可见性验证步骤；保留链接只用于提示旧流程的适用范围已变化。
:::

## 当前处理方式

1. 不依据历史截图寻找应用发布或应用审核入口。
2. 若实际任务是发布模型服务，转到[发布模型](../publish-model/)；处理模型申请时转到[模型发布审批](../model-publishing-approval/)。两者不是应用审核的替代操作。
3. 若任务确实要求应用发布与审核，先与产品负责人确认当前版本是否支持，不把旧流程执行结果作为验收依据。
