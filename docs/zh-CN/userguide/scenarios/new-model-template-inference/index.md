# 场景概览 - 异构卡纳管：新模型模板准备与部署调用

本场景串联本地模型文件准备、推理模板、实例部署与服务登记。硬件与框架按实际适配选择，不要求照搬某个昇腾 910B 或 vLLM 示例。

## 适用角色

- 运营管理员：维护模型版本、框架关联与推理模板。
- 模型提供方：基于可部署模板创建实例并登记服务、验证调用。

运营管理员交付模型版本、框架关联、适配卡型与可部署模板；提供方核对所选规格后创建实例，并在登记完成后向目标用户交付模型标识、协议和授权范围。

## 场景目标

- 新模型版本与关联集群文件状态可核对。
- 推理模板的模型版本、框架、镜像、加速卡及显存因子（用于估算显存需求的参数）匹配。
- 实例推理服务就绪，通过检测后完成私有模型登记与授权调用验证。

## 场景流程

| 阶段 | 核心结果 |
| --- | --- |
| 准备模型 | 模型文件来源、版本与集群下载状态已核对。 |
| 准备模板 | 框架关联正确，用户侧可选择可部署方案。 |
| 部署实例 | 参数与规格匹配，实例显示推理服务已就绪。 |
| 登记服务 | 冒烟检测（最小连通性检查）通过后继续私有模型向导，核对发布状态。 |
| 调用验证 | 目标账号取得有效输出并定位日志。 |

## 开始前准备

- 集群、加速卡、镜像、规格、配额与账号权限已就绪。
- 已确认模型授权、版本和业务负载要求；资源创建和真实请求测试获得授权。

## 推荐阅读顺序

1. 已有可部署模板时，直接阅读[完整指引](./template-deployment-guide)的场景 A。
2. 需要新模型版本时，运营管理员先按场景 B 准备，再将模板交给提供方。
3. 分项排查可参考[推理模板构建](../on-prem-inference-template/)与[部署状态检查](../on-prem-model-deployment-status/)。

## 完成检查

| 检查项 | 通过标准 |
| --- | --- |
| 模板就绪 | 模型文件和框架依赖明确，用户侧模板可部署。 |
| 实例就绪 | 实例资源与预览一致，服务端口与协议已核对。 |
| 发布与调用 | 完成登记及版本状态核对，授权账号调用成功并能定位日志。 |

## 常见失败分支

先按[完整指引](./template-deployment-guide#常见失败分支)中的模型文件、模板、实例和发布检测入口分层排查，不把检测通过当作发布完成。
