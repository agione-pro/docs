# 场景概览 - 多平台调度：模型资产上架

指导运营管理员在完成云资源接入后，准备运行时资产（推理镜像、推理框架）并组装为可部署的模型资产，为后续的部署与调用提供业务侧资产。

运行镜像是推理框架所需的容器运行环境，框架版本将镜像与启动配置组合为模型资产可引用的运行方案。

## 适用角色

- 运营管理员


**角色交接：** 运营管理员准备镜像、已发布的框架版本及模型部署点；模型提供方接收可选模型版本、地域与方案范围，再到快速部署验证。资产已保存或框架已发布，不等于服务已运行。

## 场景目标

- 推理镜像能够在目标云环境中拉取。
- 推理框架包含正确的端口和启动命令。
- 有权限的模型提供方能够在快速部署中选择对应模型资产。

## 场景流程

**主线：** 登记推理镜像 → 组合推理框架 → 建立模型资产 → 验证用户可部署

| 阶段 | 核心结果 |
| --- | --- |
| 1. 登记镜像 | 目标云环境能够拉取受控版本的运行镜像 |
| 2. 组合框架 | 镜像、启动命令、端口和框架类型相互兼容 |
| 3. 建立模型资产 | 元模型、部署点、云上模型、算力方案和输出协议完整关联 |
| 4. 验证可部署 | 有权限的模型提供方能在快速部署中看到模型和可用方案 |


> 可用性前提：只执行当前环境已开放的入口。快速接入或推理镜像若仅显示未开放提示，不应按历史截图继续填写；先由运营管理员确认依赖，再继续已开放的配置页。

## 开始前准备

- 已完成云资源接入和授权。
- 已准备镜像地址、框架类型、模型信息和输出 API 规则。

## 推荐阅读顺序

1. 维护推理镜像
2. 维护推理框架
3. 在模型库组装可部署模型资产

## 完成检查

按下表确认结果；未通过时，返回对应操作页排查后再继续。

| 检查项 | 通过标准 |
| --- | --- |
| 1 | 运行镜像可从目标云环境拉取，框架类型和版本正确。 |
| 2 | 推理框架的启动命令、端口和输出协议与模型匹配。 |
| 3 | 模型库条目已关联元模型、云侧部署点、算力方案和输出配置。 |
| 4 | 有权限的模型提供方在快速部署中能看到该模型及可用方案。 |

## 常见失败分支

| 现象 | 优先检查 |
| --- | --- |
| 模型库无法选择镜像或框架 | 资产状态、框架类型、地域和关联关系 |
| 用户部署页看不到模型 | 模型发布状态、部署范围、授权和租户可见性 |
| 部署后接口不可用 | 启动命令、端口、输出配置和健康状态 |
