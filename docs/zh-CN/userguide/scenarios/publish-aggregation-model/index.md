# 场景概览 - 发布聚合模型

本场景介绍如何把多个已发布模型组合成统一调用入口，并配置路由策略、计费方式和发布范围。Meta Model（元模型）是模型能力档案，路由策略决定请求在成员模型间如何分配。

## 适用角色

- 模型提供方

提供方交付聚合模型标识、协议、价格与调用范围，目标用户用自己的授权账号核对结果；需要审核时，先由运营管理员处理对应版本。

## 场景目标

- 选择可参与聚合的基础模型。
- 按页面提供的选项配置符合业务目标的路由策略。
- 提交聚合模型并进入审核或发布流程。

## 场景流程

**主线：** 选择成员模型 → 配置路由策略 → 配置计费并发布 → 验证调用结果

| 阶段 | 核心结果 |
| --- | --- |
| 1. 选择成员 | 至少选择两个已发布且属于同一元模型（Meta Model）的成员，并核对协议与模态 |
| 2. 配置路由 | 当前可选路由策略符合业务目标 |
| 3. 发布聚合 | 计费和发布范围完整，模型进入审核或模型列表 |
| 4. 验证运行 | 受控调用成功，结果与目标模型能力一致 |

## 开始前准备

- 已准备至少两个已发布、属于同一元模型（Meta Model）且有权限选择的成员模型，并核对可用状态、协议与模态。
- 已明确路由策略、计费方式和发布范围。

## 推荐阅读顺序

1. 确认基础模型和协议
2. 配置聚合策略
3. 配置计费并提交

按下表确认结果；未通过时，返回对应操作页排查后再继续。

| 检查项 | 通过标准 |
| --- | --- |
