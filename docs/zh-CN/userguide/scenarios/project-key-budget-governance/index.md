# 场景概览 - 项目、Key 与预算治理

本场景帮助平台运营方设置展示币种和 Credit 默认兑换倍率，并帮助服务商账号和平台用户创建项目、设置预算和模型白名单，以及为不同用途创建可控、可轮换的调用 Key。

## 适用角色

- 平台运营方、模型提供方、平台用户、服务商管理员

## 场景目标

- 项目具备明确用途、预算周期和超预算策略。
- 模型白名单与项目业务范围一致。
- Key 的用途、过期时间、限额和责任人清晰。
- Key 创建后能够完成受控调用，并可在活动或日志中追溯。
- 在充值和用量验证前完成平台币种与 Credit 默认兑换倍率配置。

## 场景流程

**主线：** 设置平台币种与 Credit 兑换倍率 → 创建项目 → 配置预算与模型范围 → 创建 Key → 设置限额 → 验证调用与审计

| 阶段 | 核心结果 |
| --- | --- |
| 1. 建立账务基础 | 展示币种和 Credit 默认兑换倍率已保存 |
| 2. 定义项目 | 项目用途、负责人和成员范围清晰 |
| 3. 治理预算 | 周期预算、预警阈值和超预算策略已保存 |
| 4. 限制访问 | 模型白名单和 Key 范围与项目一致 |
| 5. 验证与审计 | 调用遵守限制，变更记录可追溯 |

## 开始前准备

- 当前账号具备项目和 Key 管理权限。
- 如果由平台运营方执行，确认具备平台设置管理权限，并已确定目标币种和兑换倍率。
- 已明确项目负责人、预算周期、模型范围和超预算策略。
- 已确认使用 Model API Key 还是 System API AK/SK。

## 运营方设置：币种与 Credit 默认兑换倍率

在核对充值、项目预算或模型消耗前完成以下设置。执行账号需要具备平台设置管理权限。

1. 从 `设置 > 平台设置` 进入[平台设置](../../../usermanual/settings/operator/system-settings/platform-settings/)，选择 `币种设置`。
2. 点击 `编辑`，设置 `币种代码`、`币种名称` 和 `货币符号`。确认该配置对平台展示和结算的影响后点击 `保存`。
3. 在同一平台设置页选择 `账户与结算`，点击 `编辑`。
4. 按 `1 <币种代码> = <N> credits` 的形式设置 `Credit 默认兑换倍率`，然后点击 `保存`。请以当前环境页面显示的币种和倍率为准。

兑换倍率用于把配置币种下的授权充值金额换算为账户 Credits，不替代模型自身的计费价格。

## Credits 如何使用

1. 平台用户完成已授权的充值，平台按已配置的币种和 Credit 默认兑换倍率为账户增加 Credits。
2. 平台用户调用账号、项目、成员和 Key 均有权限使用的模型。
3. 平台按模型配置的计费方式和价格，对可计费 Token、图片、字符、时长或其他单位进行折算，得到 Credits 消耗。
4. 平台从账户可用余额中扣减计算得到的 Credits，并在用量、交易流水或账单明细中记录变化。

## 推荐阅读顺序

1. 如适用，先完成运营方的币种与 Credit 兑换倍率设置。
2. 创建并检查项目。
3. 配置预算、成员和模型白名单。
4. 创建独立用途的 Key。
5. 设置 Key 限额并验证调用。

## 完成检查

> **用途：** 以下检查是本场景的退出条件，用于确认项目成本和 API 凭据已具备可执行边界及明确责任人，再进入生产使用。

| 检查项 | 通过标准 |
| --- | --- |
| 1 | 币种代码、币种名称、货币符号和 Credit 默认兑换倍率符合当前部署。 |
| 2 | 项目名称、负责人、预算周期和用途清晰。 |
| 3 | 项目预算、预警、超预算策略和模型白名单正确。 |
| 4 | Key 用途、有效期、限额和责任人可追溯。 |
| 5 | 测试调用符合预算、白名单、Key 限额和模型计费规则。 |
