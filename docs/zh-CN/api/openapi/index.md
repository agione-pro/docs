# 模型 API（OpenAPI）

::: info 文档信息
版本：v1.0
更新日期：2026-11-06
:::

本章节说明 AGIOne 原生模型调用接口的通用约定，包括认证方式、Base URL 规则、错误码与限流策略。接口细节以当前实例实际返回为准。

## 接口约定

| 主题 | 说明 |
|------|------|
| 认证方式 | 使用 Model API Key 作为调用凭据，通过 `Authorization` 请求头传递 |
| Base URL 规则 | 区分原生接口与兼容协议两套基础路径，调用前先确认所属协议 |
| 错误码 | 按认证、额度、限流、协议四类归并，便于快速定位 |
| 限流与配额 | 受租户、项目、Key 三级额度共同约束 |

## 注意事项

1. 示例中的域名、密钥、模型标识均为占位符，实际调用请替换为当前环境的真实值。
2. 不要在文档、截图或工单中写入真实 API Key、Token 或客户数据。
3. 接口字段与错误码以当前环境实际返回为准，
