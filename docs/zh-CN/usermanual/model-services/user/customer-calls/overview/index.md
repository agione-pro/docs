# 客户调用（监控） - 概览

> 系统菜单当前将两组客户调用都显示为【客户调用】；本手册用【客户调用（监控）】区分本组。左侧菜单项为【概览】。

> 统计口径：顶部月份和日期范围决定统计范围；`按日` 切换按天聚合粒度，日期范围以控件当前显示的起止日期为准。

## 1. 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 模型提供方&用户 |
| 导航路径 | **模型及AI服务** > **客户调用** > **概览** |
| 页面路由 | `/modelone/monitoring/monitor/overview` |
| 管理对象 | 客户调用总量、成功率、Token 消耗、调用趋势和 TOP5 排行 |

**新手理解**：客户调用概览从客户视角汇总调用情况。先看客户数量、调用总量和成功率，再看调用趋势与消耗统计，最后用 TOP5 定位调用量或限流最高的客户。

## 2. 前提条件

1. 当前账号具备 **客户调用 > 概览** 的查看权限。
2. 当前统计周期内已有客户调用数据。
3. 已确认统计时间范围和维度。

## 3. 页面说明

页面标题为 `客户调用 - 概览`，提供 `客户维度` 与 `模型维度` 两个页签。

`客户维度` 包含：

- 时间与范围：顶部提供时间范围选择、`全部` 筛选和 **更多**。
- 指标卡：`客户数量`、`调用总量`、`调用成功次数`、`调用失败次数`、`限流触发次数`、`总消耗Token`。
- `调用趋势`：显示时间范围和 `全部` 筛选，提供 **更多**。
- `消耗统计`：显示 `Token 总消耗`（`总量`、`输入`、`输出`）、`平均 Token 消耗`（`输入Token`、`输出Token`）、`峰值`（`输入峰值`、`输出峰值`）。
- `客户调用TOP5`：列为 `序号`、`用户名称`、`调用总量`、`成功次数`、`失败次数`、`操作`。
- `限流触发TOP5`：列为 `序号`、`用户名称`、`触发模型限流数量`、`限流触发次数`、`操作`。

## 4. 主要操作

### 4.1 查看客户维度

1. 进入 **客户调用 > 概览**，默认打开 `客户维度`。
2. 选择时间范围和 `全部` 筛选。
3. 读取 `客户数量`、`调用总量`、成功/失败次数、限流触发次数和 `总消耗Token`。
4. 在 `调用趋势` 和 `消耗统计` 中查看走势与 Token 构成。
5. 在 `客户调用TOP5` 和 `限流触发TOP5` 中定位重点客户。

### 4.2 切换模型维度

1. 点击 `模型维度` 页签。
2. 按页面提供的模型维度条件查看对应统计。

### 4.3 查看更多

1. 点击指标区或趋势区的 **更多**。
2. 按展开的选项查看扩展信息或进入明细。

## 5. 参数速查表

| 字段名称 | 是否必填 | 字段类型 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| 时间范围 | 是 | 日期范围 | `2026-11-01` 至 `2026-11-03` | 统计时间范围 |
| 客户数量 | 系统统计 | 数值 | `0` | 产生调用的客户数 |
| 调用总量 | 系统统计 | 数值 | `0` | 客户调用总量 |
| 调用成功次数 | 系统统计 | 数值 | `0` | 成功调用数 |
| 调用失败次数 | 系统统计 | 数值 | `0` | 失败调用数 |
| 限流触发次数 | 系统统计 | 数值 | `0` | 触发限流的次数 |
| 总消耗Token | 系统统计 | 数值 | `0` | 客户消耗的 Token 总量 |
| Token 总消耗 | 系统统计 | 数值 | `0 Tokens` | 总量、输入、输出 |
| 平均 Token 消耗 | 系统统计 | 数值 | `0 Tokens` | 输入与输出平均数 |
| 峰值 | 系统统计 | 数值 | `0 Tokens` | 输入与输出峰值 |
| 用户名称 | 系统统计 | 文本 | `客户 A` | TOP5 中的客户名称 |
| 触发模型限流数量 | 系统统计 | 数值 | `0` | 触发限流的模型数 |
| 限流触发次数 | 系统统计 | 数值 | `0` | TOP5 中的限流次数 |

## 6. 踩坑提示

- `客户维度` 与 `模型维度` 的统计口径不同，切换后不要直接比较同名指标。
- `总消耗Token` 是 Token 总量，不是金额；金额与收益请到模型收益页面查看。
- 当前范围没有数据时 TOP5 显示 `暂无数据`，趋势图可能为空。
- 页面时间范围由当前日期决定，跨天查看时先确认范围。

## 7. 结果校验

| 核对项 | 界面上可直接看到 |
| --- | --- |
| 页签可切换 | `客户维度` 与 `模型维度` 可正常切换 |
| 指标完整 | 显示客户数量、调用总量、成功/失败次数、限流次数、总消耗Token |
| 趋势可读 | `调用趋势` 显示当前时间范围 |

## 8. 常见问题

#### 指标和排行都是 0 或空

**现象**：客户数量、调用总量为 `0`，TOP5 显示 `暂无数据`。

**处理方式**：确认当前时间范围内有客户调用；扩大时间范围后重试。

#### 客户维度与模型维度数据不一致

**现象**：两个页签的调用总量不同。

**处理方式**：两个页签按不同维度聚合，口径不同；需要总量时以客户维度为准，并核对时间范围一致。

## 9. 注意事项

- 页面包含客户名称和调用数据，不要截图外发。
- 统计数据按时间范围汇总，跨范围比较前先固定口径。
