## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 用户 |
| 导航路径 | 模型及AI服务 > 创作空间 > 我的部署 |
| 页面路由 | `/modelone/my-deployments/models` |
| 管理对象 | 跨算力环境（On-Prem 异构卡纳管与 On-Cloud 多平台调度）的模型部署实例集中概览与快速跳转入口 |

#### 新手理解

我的部署是模型及AI服务下的实例看板。用户无需频繁切换顶部导航，即可集中查看异构卡纳管（On-Prem）和多平台调度（On-Cloud）部署的全部模型服务。本页主要提供快速检索与跨子系统入口；点击实例或快速部署按钮后，会跳转至底层算力子系统完成创建与生命周期管理。

#### 术语速查

| 术语 | 说明 |
| --- | --- |
| On-Prem 部署 | 运行在平台本地纳管的异构加速卡集群上的模型实例；点击后跳转至异构卡纳管子系统管理。 |
| On-Cloud 部署 | 调度并部署在外部云平台或第三方多架构算力平台上的模型服务；点击后跳转至多平台调度子系统管理。 |

## 前提条件

- 已成功登录 AGIOne 平台且所在账号具备模型部署查看权限。
- 若需通过跳转发起新部署，当前租户需具备可用算力配额或账户余额正常。

## 主要操作

### 1. 切换算力环境查看部署列表

在页面上方点击【On-Prem】或【On-Cloud】标签页：
- 点击 **On-Prem**：系统展示运行在本地自建异构算力集群上的模型服务列表。
- 点击 **On-Cloud**：系统展示基于多平台调度托管在外部公有云或第三方算力平台上的模型服务列表。

### 2. 按条件筛选检索实例

- 在地域/可用区下拉框中选择目标算力区域（默认展示全部）。
- 在形态切换栏选择【全部】、【单实例】或【集群】，筛选对应形态的部署实例。
- 在状态下拉框选择过滤运行中、停止、异常等生命周期状态。
- 在搜索框中输入实例名称关键词，点击搜索按钮进行精确匹配，点击重置按钮清空输入并恢复全量。

### 3. 跳转至底层子系统完成实例管理

本页面作为实例看板，核心管理操作均直通底层算力子系统：
- **查看与运维实例**：点击列表中目标实例的名称或操作按钮，系统将自动跳转至【On-Prem】（`/powerone/quickstart/model-service`）或【On-Cloud】（`/infrahub/user/model/deployment`）的实例控制台，在对应子系统内完成实例的启动、停止、删除、查看日志与监控指标。
- **发起新建部署**：点击右上角【前往快速部署】或筛选栏右侧【自定义部署】，系统将直接跳转至对应子系统的部署向导页面，按提示选定算力规格与模型镜像即可完成交付。

## 参数速查表

| 字段名称 | 是否必填 | 字段类型 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| 地域 | 否 | 下拉选择 | 全部 | 筛选指定地域或可用区下部署的模型实例记录 |
| 形态 | 否 | 分段单选 | 全部 | 选项包括全部、单实例、集群，用于按部署架构模式过滤实例 |
| 状态 | 否 | 下拉选择 | 全部状态 | 选项包括全部状态及具体运行状态，用于按生命周期阶段过滤实例 |
| 按实例名称搜索 | 否 | 文本输入 | qwen2.5 | 输入模型实例名称关键词进行精准过滤 |

## 踩坑提示

- 点击列表中的实例或部署按钮后，浏览器将跳转至对应的 On-Prem 或 On-Cloud 子系统完成操作，这属于跨系统跳转的预期设计，并非页面异常。
- 若在当前算力环境列表中未找到目标服务，请检查该服务是否部署在另一环境，并在顶部的 On-Prem 与 On-Cloud 标签页之间切换确认。

## 常见问题

**问题现象：** 点击操作按钮后为什么会离开当前模型服务子系统？
**可能原因：** 本页面作为统一汇聚看板，实际算力实例托管在底层特定算力子系统中。
**处理方式：** 属于系统正常流程，在跳转后的底层子系统页面中按标准指引完成实例操作即可，完成后可随时点击顶部导航【模型及AI服务】返回。

## 注意事项

- 本页面不直接提供修改模型显存或容器规格等底层配置的功能，所有基础设施层面的变更请在跳转后的算力子系统中操作。
- 实例删除或停止操作生效后，本页面的汇聚列表会有数秒同步延迟，以底层子系统实际运行状态为准。
