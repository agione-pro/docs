# 快速入门

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员、模型提供方、模型调用方 |
| 导航路径 | 用户手册 > AI基础设施(On-Prem) > 快速入门 |
| 页面路由 | `N/A` |
| 管理对象 | 角色边界、资源层级、准备顺序和页面入口 |

#### 新手理解

快速入门像一张上手路线图。它说明三类角色各自负责什么，并把地域、可用区、集群、资源规格、模板和实例按先后关系串起来。

#### 术语表

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 运营管理员 | Operator | 维护资源池、模板、配额和系统配置的角色。 |
| 模型提供方 | Model Provider | 创建开发资源、部署模型并维护运行实例的角色。 |
| 模型调用方 | Model Consumer | 使用已开放能力并查看相关配额、用量和监控的角色。 |

#### 推荐操作顺序

先确认角色和目标，再检查地域与集群；底座资源完成后准备规格和模板，最后创建实例并查看用量与监控。

#### 小白先看

先确认当前任务是否涉及角色边界、资源层级、准备顺序和页面入口，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

1. 已确认当前账号角色是运营管理员还是模型提供方或模型调用方。
2. 已明确目标资源在本地集群或私有化资源池中。
3. 涉及实例创建前，已确认地域、规格、镜像、存储和配额。

## 主要操作

### 确认角色职责

1. 运营管理员负责资源池、模板、配额和系统配置。
2. 模型提供方负责开发资源、镜像和模型实例。
3. 模型调用方在已开放范围内使用能力并查看相关状态。

### 确认资源准备顺序

1. 先创建地域和可用区，再注册集群。
2. 集群可用后维护加速卡、规格指标和资源规格。
3. 准备模型、框架和推理模板后再创建实例。

### 选择下一入口

1. 底座未完成时进入 **"地域/可用区"** 或 **"集群管理"**。
2. 规格未完成时进入 **"规格指标"** 和 **"资源规格"**。
3. 模板与配额可用后进入 **"部署模板"**。

## 踩坑提示

- 用户侧看不到资源时，先确认地域、可用区、权限和筛选条件，再判断资源是否未开放。
- 实例创建失败时，不要只看规格，还要同时检查配额、镜像、存储挂载和集群状态。
- 涉及 kubeconfig、镜像仓库、对象存储或块存储凭据时，只在平台受控入口配置，不写入文档或截图。
- 快速入门用于确认入口、角色边界和资源关系；执行创建、删除、禁用、解绑、额度调整或资源变更前，应按对应功能页核对影响并取得授权。
- 账号、角色、Key 和权限配置属于 Settings 子系统，不在 On-Prem 快速入门中记录真实账号、Token、AK/SK、API Key、租户、资源 ID、集群 ID、节点 IP、Endpoint 或测试参数。

## 常见问题

#### 快速入门中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的角色边界、资源层级、准备顺序和页面入口。

**可能原因：**

- 筛选条件仍生效。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 重置筛选
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

#### 快速入门的操作入口不可用

**问题现象：**

新增、注册或维护入口不可见或不可点击。

**可能原因：**

- 当前角色权限不足。
- 页面处于只读状态。
- 依赖对象不满足条件。

**处理方式：**

1. 检查运营管理员权限
2. 核对页面提示
3. 先完成依赖对象配置。

#### 快速入门的必填项没有可选值

**问题现象：**

表单能打开，但下拉框为空。

**可能原因：**

- 候选对象未启用。
- 所属范围不一致。
- 当前账号不可见。

**处理方式：**

1. 到候选对象页面核对状态
2. 确认归属关系
3. 检查可见范围后刷新表单。

#### 快速入门操作后状态异常

**问题现象：**

提交后记录存在，但状态不是预期值。

**可能原因：**

- 连通性或校验失败。
- 关联对象异常。
- 后台处理尚未完成。

**处理方式：**

1. 查看页面提示和更新时间
2. 检查关联对象
3. 按状态阶段排查处理任务。

#### 下游页面无法使用快速入门

**问题现象：**

当前页状态正常，但下游页面无法选择或关联角色边界、资源层级、准备顺序和页面入口。

**可能原因：**

- 可见范围不匹配。
- 对象未启用。
- 下游缓存未刷新。

**处理方式：**

1. 核对启用状态和归属
2. 检查角色可见范围
3. 刷新下游页面并重新选择。

## 注意事项

- 本文用于平台级入门，不替代各功能页的具体字段说明。
- 涉及删除、禁用、下线、额度调整和资源解绑的操作，应先确认影响范围、维护窗口和回退方案。
- 截图前检查页面中是否暴露内部地址、凭据、密钥、证书或完整 kubeconfig。

- 如果问题是账号、角色、权限、Key 或租户成员，进入 Settings；如果问题是资源不可见、规格不可用或实例排队，进入 On-Prem 资源、配额和监控页面。
