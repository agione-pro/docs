# 块存储

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 模型提供方 |

| 页面路由 | `/powerone/storage-service/block` |
| 管理对象 | 块存储卷、容量、挂载关系和卷状态 |

#### 新手理解

块存储像给实例挂一块独立硬盘，适合需要持久化写入、独立卷或块设备语义的任务。它不是共享目录，多个实例同时读写前需要确认平台是否支持对应挂载方式。

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 卷 | Volume | Volume |
| 容量 | Capacity | Capacity |
| 挂载 | Mount | Mount |

#### 推荐操作顺序

先确认块存储卷、容量、挂载关系和卷状态的前置依赖，再按主要操作顺序处理，最后执行结果校验并进入后续页面。

#### 小白先看

先确认当前任务是否涉及块存储卷、容量、挂载关系和卷状态，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

1. 运营管理员已在目标地域接入并开放块存储组件。
2. 当前账号具备查看和使用块存储的权限。
3. 租户配额、容量和实例规格满足使用要求。
4. 需要挂载到实例时，实例所在地域、集群和存储能力一致。

## 主要操作

### 查看存储资源

1. 进入对应存储服务页面，按名称、项目、状态、容量或更新时间筛选。
2. 打开详情，核对容量、已用空间、访问方式、挂载或连接状态和创建时间。
3. 无结果时重置筛选并检查项目与地域；内部地址和访问凭据不得外发。
4. 容量或状态异常时先检查配额、事件和关联实例，不重复创建资源。

### 管理容量、挂载或访问

1. 打开目标资源的操作菜单，确认扩容、挂载、卸载、权限或删除入口的影响。
2. 变更前记录当前容量、关联实例和数据保护状态。
3. 扩容、卸载或删除前确认任务和备份；执行最终操作前，应确认资源、数据和影响，并取得授权。
4. 获批变更后检查容量、连接状态和事件；异常时停止后续操作并按恢复流程处理。

### 创建卷

#### 功能可用时页面会展示

| 区域 | 说明 |
| --- | --- |
| 列表区 | 展示已有卷、容量、状态和更新时间。 |
| 创建入口 | 新增块存储卷。 |
| 挂载入口 | 将卷关联到实例或容器路径。 |
| 操作入口 | 编辑、扩容、卸载、删除或查看详情，具体以页面提供能力为准。 |

#### 操作步骤

1. 进入 `AI基础设施 > On-Prem > 存储服务 > 块存储`。
2. 确认右上角地域。
3. 如页面提供创建入口，填写名称、容量、访问策略和描述。
4. 提交后返回列表查看状态。
5. 在创建实例或实例详情中选择该卷并设置容器内路径。

## 参数速查表

| 字段名称 | 是否必填 | 字段类型 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| 卷名称 | 必填 | 文本 | `train-data-volume` | 块存储卷展示名称。 |
| 容量 | 必填 | 数字 | `100GiB` | 卷可使用空间。 |
| 访问模式 | 条件必填 | 枚举 | `ReadWriteOnce` | 控制卷是否允许单实例或多实例挂载。 |
| 挂载路径 | 条件必填 | 文本 | `/mnt/data` | 实例或容器内访问路径。 |
| 卷状态 | 系统生成 | 枚举 | `可用` | 用于判断是否可挂载、扩容或删除。 |

#### 挂载、卸载和容量确认

#### 挂载

1. 打开实例创建页或存储挂载入口。
2. 选择目标块存储资源。
3. 填写容器内路径，例如 `/mnt/data` 或 `/mnt/output`。
4. 提交后查看实例事件和日志，确认挂载成功。

#### 卸载

1. 确认没有运行中的进程正在读写该路径。
2. 在实例或存储操作入口执行卸载。
3. 刷新页面确认挂载关系解除。

#### 容量确认

1. 在块存储列表查看容量和状态。
2. 在实例内执行 `df -h` 或应用侧容量检查。
3. 如容量不足，按页面能力扩容或联系运营管理员调整配额。

## 踩坑提示

- 块存储通常不适合多个实例同时读写同一路径，使用前确认访问模式。
- 挂载路径不要覆盖系统目录、启动目录或镜像内关键目录。
- 删除卷前确认没有运行中实例、训练任务或输出产物依赖。

### 替代路径

- 需要保存模型文件、数据集或产物包时，优先考虑 [对象存储](../object-storage/)。
- 需要共享目录语义时，使用文件存储或运营管理员配置的集群共享存储。
- 需要独立卷能力时，使用块存储；如果页面未开放，联系运营管理员确认目标地域是否具备底层存储组件。

### 排障信息准备

块存储异常时，先准备以下信息，便于判断是卷创建、挂载、扩容还是卸载风险：

| 信息 | 示例 | 作用 |
| --- | --- | --- |
| 卷 ID | `pvc-20260713001` | 定位目标块卷。 |
| 挂载实例 | `infer-001` | 判断卷被哪个实例使用。 |
| 容量 | `100 GiB` | 判断容量是否不足或扩容是否生效。 |
| 存储类 | `ceph-rbd-prod` | 判断底层块存储组件和策略。 |
| 挂载状态 | `Pending / Mounted / Failed` | 决定下一步看调度、CSI 还是实例事件。 |

## 常见问题

#### 块存储中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的块存储卷、容量、挂载关系和卷状态。

**可能原因：**

- 筛选条件仍生效。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 重置筛选
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

#### 块存储的操作入口不可用

**问题现象：**

新增、注册或维护入口不可见或不可点击。

**可能原因：**

- 当前角色权限不足。
- 页面处于只读状态。
- 依赖对象不满足条件。

**处理方式：**

1. 检查运营管理员权限
2. 核对页面提示
3. 先完成依赖对象配置。

#### 块存储的必填项没有可选值

**问题现象：**

表单能打开，但下拉框为空。

**可能原因：**

- 候选对象未启用。
- 所属范围不一致。
- 当前账号不可见。

**处理方式：**

1. 到候选对象页面核对状态
2. 确认归属关系
3. 检查可见范围后刷新表单。

#### 块存储操作后状态异常

**问题现象：**

提交后记录存在，但状态不是预期值。

**可能原因：**

- 连通性或校验失败。
- 关联对象异常。
- 后台处理尚未完成。

**处理方式：**

1. 查看页面提示和更新时间
2. 检查关联对象
3. 按状态阶段排查处理任务。

#### 下游页面无法使用块存储

**问题现象：**

当前页状态正常，但下游页面无法选择或关联块存储卷、容量、挂载关系和卷状态。

**可能原因：**

- 可见范围不匹配。
- 对象未启用。
- 下游缓存未刷新。

**处理方式：**

1. 核对启用状态和归属
2. 检查角色可见范围
3. 刷新下游页面并重新选择。

## 注意事项

- 删除或卸载前先确认没有运行中实例依赖。
- 挂载路径不要覆盖系统目录、应用目录或镜像内关键目录。
