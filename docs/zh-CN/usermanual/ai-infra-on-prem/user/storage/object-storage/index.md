# 对象存储

| 项目 | 内容 |

#### 新手理解

对象存储像模型和数据的云盘，用桶和对象保存文件、数据集、模型包和输出结果。它适合按路径上传、下载和共享文件，但不等同于可直接挂载的 POSIX 共享目录。

#### 小白先看

先确认当前任务是否涉及对象存储桶、对象文件、对象路径和地域内对象存储能力，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

1. 目标地域已由运营管理员开放对象存储能力。
2. 当前账号具备查看、创建桶和管理对象的权限。
3. 桶名称、对象路径和数据保留策略已规划。
4. 如用于作业，作业所在地域应能访问该对象存储。

## 主要操作

### 查看存储资源

1. 进入对应存储服务页面，按名称、项目、状态、容量或更新时间筛选。
2. 打开详情，核对容量、已用空间、访问方式、挂载或连接状态和创建时间。
3. 无结果时重置筛选并检查项目与地域；内部地址和访问凭据不得外发。
4. 容量或状态异常时先检查配额、事件和关联实例，不重复创建资源。

### 管理容量、挂载或访问

1. 打开目标资源的操作菜单，确认扩容、挂载、卸载、权限或删除入口的影响。
2. 变更前记录当前容量、关联实例和数据保护状态。
3. 扩容、卸载或删除前确认任务和备份；执行最终操作前，应确认资源、数据和影响，并取得授权。
4. 获批变更后检查容量、连接状态和事件；异常时停止后续操作并按恢复流程处理。

### 新增桶

#### 操作步骤

1. 进入 `AI基础设施 > On-Prem > 存储服务 > 对象存储`。
2. 确认右上角地域。
3. 点击 **"新增桶（Add Bucket）"**。
4. 填写 Bucket Name。
5. 点击 **"确认（Confirm）"** 提交。

## 参数速查表

| 字段名称 | 是否必填 | 字段类型 | 示例 | 说明 |

## 踩坑提示

- 存储路径、桶名、AK/SK 和 NFS 路径截图前必须脱敏。
- 挂载失败时先确认地域、权限和存储组件状态。
- 删除存储资源前确认没有实例、任务或输出产物依赖。

### 配置规则与影响

- 桶属于地域内存储资源，跨地域访问能力以运营管理员配置为准。
- 对象存储适合非结构化文件，不适合需要 POSIX 共享目录语义的场景。
- 删除桶或对象前必须确认没有实例、模型、脚本或作业依赖。
- 对象路径可以进入启动命令或参数，但不要把访问密钥写进命令。

## 常见问题

#### 对象存储中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的对象存储桶、对象文件、对象路径和地域内对象存储能力。

**可能原因：**

- 筛选条件仍生效。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 重置筛选
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

#### 对象存储的操作入口不可用

**问题现象：**

新增、注册或维护入口不可见或不可点击。

**可能原因：**

- 当前角色权限不足。
- 页面处于只读状态。
- 依赖对象不满足条件。

**处理方式：**

1. 检查运营管理员权限
2. 核对页面提示
3. 先完成依赖对象配置。

#### 对象存储的必填项没有可选值

**问题现象：**

表单能打开，但下拉框为空。

**可能原因：**

- 候选对象未启用。
- 所属范围不一致。
- 当前账号不可见。

**处理方式：**

1. 到候选对象页面核对状态
2. 确认归属关系
3. 检查可见范围后刷新表单。

#### 对象存储操作后状态异常

**问题现象：**

提交后记录存在，但状态不是预期值。

**可能原因：**

- 连通性或校验失败。
- 关联对象异常。
- 后台处理尚未完成。

**处理方式：**

1. 查看页面提示和更新时间
2. 检查关联对象
3. 按状态阶段排查处理任务。

#### 下游页面无法使用对象存储

**问题现象：**

当前页状态正常，但下游页面无法选择或关联对象存储桶、对象文件、对象路径和地域内对象存储能力。

**可能原因：**

- 可见范围不匹配。
- 对象未启用。
- 下游缓存未刷新。

**处理方式：**

1. 核对启用状态和归属
2. 检查角色可见范围
3. 刷新下游页面并重新选择。

## 注意事项

- 不要在对象路径或文件名中写入密钥、账号、token 或客户敏感信息。
- 重要数据删除前先确认备份和依赖关系。
