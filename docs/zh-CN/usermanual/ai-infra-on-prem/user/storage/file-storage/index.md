#### 新手理解

文件存储像团队共享文件夹，适合多个实例或作业读取同一批数据、模型文件或输出目录。它强调目录和文件语义，和块存储的独立硬盘语义不同。

#### 术语表

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 共享目录 | Shared Directory | Shared Directory |
| NFS | NFS | NFS |
| 挂载路径 | Mount Path | Mount Path |

#### 推荐操作顺序

先确认共享文件系统、目录、容量、挂载关系和访问策略的前置依赖，再按主要操作顺序处理，最后执行结果校验并进入后续页面。

#### 小白先看

先确认当前任务是否涉及共享文件系统、目录、容量、挂载关系和访问策略，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

1. 运营管理员已在目标地域接入并开放文件存储组件。
2. 当前账号具备查看和使用文件存储的权限。
3. 租户配额、容量和实例规格满足使用要求。
4. 需要挂载到实例时，实例所在地域、集群和存储能力一致。

## 主要操作

### 查看存储资源

1. 进入对应存储服务页面，按名称、项目、状态、容量或更新时间筛选。
2. 打开详情，核对容量、已用空间、访问方式、挂载或连接状态和创建时间。
3. 无结果时重置筛选并检查项目与地域；内部地址和访问凭据不得外发。
4. 容量或状态异常时先检查配额、事件和关联实例，不重复创建资源。

### 管理容量、挂载或访问

1. 打开目标资源的操作菜单，确认扩容、挂载、卸载、权限或删除入口的影响。
2. 变更前记录当前容量、关联实例和数据保护状态。
3. 扩容、卸载或删除前确认任务和备份；执行最终操作前，应确认资源、数据和影响，并取得授权。
4. 获批变更后检查容量、连接状态和事件；异常时停止后续操作并按恢复流程处理。

### 创建共享目录

#### 功能可用时页面会展示

| 区域 | 说明 |
| --- | --- |
| 列表区 | 展示已有共享目录、容量、状态和更新时间。 |
| 创建入口 | 新增文件存储目录或声明。 |
| 挂载入口 | 将共享目录关联到实例或容器路径。 |
| 操作入口 | 编辑、扩容、卸载、删除或查看详情，具体以页面提供能力为准。 |

#### 操作步骤

1. 进入 `AI基础设施 > On-Prem > 存储服务 > 文件存储`。
2. 确认右上角地域。
3. 如页面提供创建入口，填写名称、容量、访问策略和描述。
4. 提交后返回列表查看状态。
5. 在创建实例或实例详情中选择该共享目录并设置容器内路径。

## 参数速查表

| 字段名称 | 是否必填 | 字段类型 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| 共享目录名称 | 必填 | 文本 | `shared-dataset` | 文件存储资源展示名称。 |
| 容量 | 必填 | 数字 | `500GiB` | 共享目录可用空间。 |
| 访问策略 | 条件必填 | 枚举 | `读写` | 控制只读或读写访问。 |
| 挂载路径 | 条件必填 | 文本 | `/mnt/shared` | 实例或容器内访问路径。 |
| 共享状态 | 系统生成 | 枚举 | `可用` | 用于判断是否可挂载、扩容或删除。 |

#### 挂载、卸载和容量确认

#### 挂载

1. 打开实例创建页或存储挂载入口。
2. 选择目标文件存储资源。
3. 填写容器内路径，例如 `/mnt/data` 或 `/mnt/output`。
4. 提交后查看实例事件和日志，确认挂载成功。

#### 卸载

1. 确认没有运行中的进程正在读写该路径。
2. 在实例或存储操作入口执行卸载。
3. 刷新页面确认挂载关系解除。

#### 容量确认

1. 在文件存储列表查看容量和状态。
2. 在实例内执行 `df -h` 或应用侧容量检查。
3. 如容量不足，按页面能力扩容或联系运营管理员调整配额。

## 踩坑提示

- 共享目录中的文件会被多个任务看到，写入前确认命名和覆盖风险。
- NFS 或共享存储路径截图前必须脱敏。
- 高并发小文件读写可能影响性能，必要时拆分目录或改用对象存储。

### 替代路径

- 需要保存模型文件、数据集或产物包时，优先考虑 [对象存储](../object-storage/)。
- 需要共享目录语义时，使用文件存储或运营管理员配置的集群共享存储。
- 需要独立卷能力时，使用块存储；如果页面未开放，联系运营管理员确认目标地域是否具备底层存储组件。

### 排障信息准备

文件存储异常时，先准备以下信息，便于判断是共享路径、权限、客户端节点还是多节点访问问题：

| 信息 | 示例 | 作用 |
| --- | --- | --- |
| 文件系统 ID | `fs-20260713001` | 定位目标文件存储。 |
| 挂载路径 | `/mnt/share` | 判断容器内路径是否冲突。 |
| 权限 | `读写 / 只读` | 判断写入失败是否由权限导致。 |
| 客户端节点 | `node-gpu-01` | 判断哪台节点挂载失败。 |
| 共享目录 | `/exports/models` | 核对 NFS 导出路径和租户目录。 |

## 常见问题

#### 文件存储中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的共享文件系统、目录、容量、挂载关系和访问策略。

**可能原因：**

- 筛选条件仍生效。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 重置筛选
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

#### 文件存储的操作入口不可用

**问题现象：**

新增、注册或维护入口不可见或不可点击。

**可能原因：**

- 当前角色权限不足。
- 页面处于只读状态。
- 依赖对象不满足条件。

**处理方式：**

1. 检查运营管理员权限
2. 核对页面提示
3. 先完成依赖对象配置。

#### 文件存储的必填项没有可选值

**问题现象：**

表单能打开，但下拉框为空。

**可能原因：**

- 候选对象未启用。
- 所属范围不一致。
- 当前账号不可见。

**处理方式：**

1. 到候选对象页面核对状态
2. 确认归属关系
3. 检查可见范围后刷新表单。

#### 文件存储操作后状态异常

**问题现象：**

提交后记录存在，但状态不是预期值。

**可能原因：**

- 连通性或校验失败。
- 关联对象异常。
- 后台处理尚未完成。

**处理方式：**

1. 查看页面提示和更新时间
2. 检查关联对象
3. 按状态阶段排查处理任务。

#### 下游页面无法使用文件存储

**问题现象：**

当前页状态正常，但下游页面无法选择或关联共享文件系统、目录、容量、挂载关系和访问策略。

**可能原因：**

- 可见范围不匹配。
- 对象未启用。
- 下游缓存未刷新。

**处理方式：**

1. 核对启用状态和归属
2. 检查角色可见范围
3. 刷新下游页面并重新选择。

## 注意事项

- 删除或卸载前先确认没有运行中实例依赖。
- 挂载路径不要覆盖系统目录、应用目录或镜像内关键目录。
