# 在线IDE

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 模型提供方 |
| 导航路径 | AI基础设施 > On-Prem > 开发资源 > 在线IDE |
| 页面路由 | `/powerone/dev-training/dev-ide` |
| 管理对象 | 在线开发环境、单节点 IDE、集群 IDE、镜像、规格和运行状态 |

#### 新手理解

在线 IDE 像运行在资源池里的云端开发机。你不需要本地安装 GPU 环境，只要选择镜像和规格，平台会创建一个可访问的开发环境。

| --- | --- | --- |

#### 推荐操作顺序

1. 进入 `开发资源 > 在线IDE`。
2. 查看现有 IDE 列表和状态。
3. 点击 **"创建 IDE（Create IDE）"**。
4. 选择 `单节点（Single Node）` 或 `集群（Cluster）` 部署类型。
5. 继续填写镜像、规格、存储和启动参数。
6. 创建后返回列表查看状态并进入 IDE。

#### 小白先看

先确认当前任务是否涉及在线开发环境、单节点 IDE、集群 IDE、镜像、规格和运行状态，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

1. 当前账号具备创建在线 IDE 的权限。
2. 目标地域有可用规格和配额。
3. 已有可用镜像，且镜像中包含所需开发工具。
4. 如需挂载数据或代码目录，相关存储已准备。

## 主要操作

### 查看资源实例

1. 进入对应开发资源页面，按名称、项目、状态、规格或更新时间筛选。
2. 打开详情，核对镜像、规格、存储、网络、运行状态和创建时间。
3. 无结果时重置筛选并检查项目与地域；内部地址和凭据外发前必须脱敏。
4. 状态异常时先查看事件和配额，不重复创建实例。

### 连接或管理实例状态

1. 打开目标实例详情，确认连接入口、运行状态和关联存储。
2. 连接前确认访问权限和网络范围；只使用平台提供的安全入口。
3. 启动、停止、重启或删除前确认任务与数据已保存；执行这些动作前，应确认资源、数据和影响，并取得授权。
4. 获批操作后检查状态和事件；异常时停止重试并按日志升级。

### 创建在线 IDE

#### 适用场景

当需要一个可交互的开发、调试或 Notebook 环境时，创建在线 IDE。

#### 操作前确认

1. 已确认目标规格和配额可用。
2. 已确认镜像包含 Python、CUDA、框架或其他开发依赖。
3. 已确认运行周期，避免长时间空转消耗资源。

#### 操作步骤

1. 进入 `AI基础设施 > On-Prem > 开发资源 > 在线IDE`。
2. 点击 **"创建 IDE"**。
3. 在部署类型页面选择 `单节点` 或 `集群`。

![选择部署类型](./images/deployment-type.png)

4. 点击 **"填写参数"**，进入在线 IDE 创建配置页面。
5. 按页面字段查看或填写 IDE 名称、地域、镜像、规格、存储挂载和启动命令等配置。
6. 核对配置项、资源规格、存储路径和运行方式。

![创建在线 IDE](./images/create-ide.png)

## 参数速查表

| 字段名称 | 是否必填 | 字段类型 | 说明 |
| --- | --- | --- | --- |
| IDE 名称 | 必填 | 文本 | 在线 IDE 展示名称。 |
| 部署类型 | 必填 | 单选 | 选择单节点或集群形态。 |
| 地域 | 必填 | 下拉选择 | 选择创建在线 IDE 的目标地域。 |
| 镜像 | 必填 | 下拉选择 | 选择开发环境镜像。 |
| 资源规格 | 必填 | 下拉选择 | 选择在线 IDE 使用的算力规格。 |
| 存储挂载 | 否 | 路径 | 配置代码、数据或输出目录的挂载路径。 |
| 启动命令 | 否 | 文本 | 配置在线 IDE 启动或运行命令。 |

## 踩坑提示

- 集群模式可能需要更多配额，普通调试优先使用单节点。
- 镜像缺少依赖时，IDE 能启动但代码可能运行失败。
- `提交`、`确定`、`确认` 属于最终动作。
- 创建在线 IDE 会占用配额和集群资源。

- 不写真实租户、地域、镜像地址、规格 ID、存储路径、Token、密码、Endpoint、启动参数或测试数据。

### 配置规则与影响

- 在线 IDE 会占用配额和集群资源，运行时间越长消耗越多。
- 镜像、规格和存储由运营管理员配置，模型提供方或模型调用方只能选择可见项。
- 停止、删除或释放 IDE 前，应确认代码和输出已保存到持久化目录。

## 常见问题

#### 在线IDE中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的在线开发环境、单节点 IDE、集群 IDE、镜像、规格和运行状态。

**可能原因：**

- 筛选条件仍生效。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 重置筛选
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

#### 在线IDE的操作入口不可用

**问题现象：**

新增、注册或维护入口不可见或不可点击。

**可能原因：**

- 当前角色权限不足。
- 页面处于只读状态。
- 依赖对象不满足条件。

**处理方式：**

1. 检查运营管理员权限
2. 核对页面提示
3. 先完成依赖对象配置。

#### 在线IDE的必填项没有可选值

**问题现象：**

表单能打开，但下拉框为空。

**可能原因：**

- 候选对象未启用。
- 所属范围不一致。
- 当前账号不可见。

**处理方式：**

1. 到候选对象页面核对状态
2. 确认归属关系
3. 检查可见范围后刷新表单。

#### 在线IDE操作后状态异常

**问题现象：**

提交后记录存在，但状态不是预期值。

**可能原因：**

- 连通性或校验失败。
- 关联对象异常。
- 后台处理尚未完成。

**处理方式：**

1. 查看页面提示和更新时间
2. 检查关联对象
3. 按状态阶段排查处理任务。

#### 下游页面无法使用在线IDE

**问题现象：**

当前页状态正常，但下游页面无法选择或关联在线开发环境、单节点 IDE、集群 IDE、镜像、规格和运行状态。

**可能原因：**

- 可见范围不匹配。
- 对象未启用。
- 下游缓存未刷新。

**处理方式：**

1. 核对启用状态和归属
2. 检查角色可见范围
3. 刷新下游页面并重新选择。

## 注意事项

- 不要把账号密码、Token、私钥、Endpoint、启动参数或测试数据写入 Notebook、代码仓库或截图。
- 创建前确认存储挂载路径，避免输出只保存在临时容器目录。

## 后续操作

1. 进入 IDE 编写和调试代码。
2. 将重要代码、数据和输出保存到持久化存储。
3. 不用时停止或释放 IDE。
