# 概览

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员、模型提供方、模型调用方 |
| 导航路径 | 用户手册 > AI基础设施(On-Prem) > 概览 |
| 页面路由 | `N/A` |
| 管理对象 | 地域、可用区、集群、资源规格、模板、用量和监控入口 |

#### 新手理解

概览像本地算力手册的目录。运营管理员先准备地域、集群和资源规格，模型提供方再创建开发资源或模型实例，模型调用方查看与自身业务相关的配额和监控结果。

#### 术语表

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 地域 | Region | 承载一组可用区、组件和集群的资源边界。 |
| 集群 | Cluster | 提供 CPU、内存、加速卡和存储资源的计算集合。 |
| 资源规格 | Resource Spec | 用户创建实例时选择的 CPU、内存和加速卡组合。 |

#### 推荐操作顺序

先阅读快速入门确认角色和资源层级，再由运营管理员完成资源池与模板配置，随后由模型提供方创建实例，最后通过配额、用量和监控页面校验。

#### 小白先看

先确认当前任务是否涉及地域、可用区、集群、资源规格、模板、用量和监控入口，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

1. 已明确当前账号是运营管理员还是模型提供方或模型调用方。
2. 已选择目标地域、可用区或资源池。
3. 涉及实例创建前，已确认规格、镜像、存储、配额和集群能力。
4. 涉及故障排查时，准备脱敏后的时间范围、资源编号、错误信息和日志摘要。

## 主要操作

### 定位运营管理员入口

1. 从`运营管理员`分组进入资源池、模板、配额&计量、监控或系统页面。
2. 按当前阶段选择对象页，不把搜索、筛选或分页当作独立业务操作。
3. 完成后按结果校验表确认状态，再交接给模型提供方。

### 定位模型提供方入口

1. 从`用户`分组进入模型部署、开发资源、存储服务或镜像服务。
2. 创建实例前确认模板、资源规格和配额均可用。
3. 创建后在实例、用量和监控页面核对结果。

### 串联跨角色主链路

1. 运营管理员依次完成地域、可用区、集群、规格和模板。
2. 模型提供方创建模型实例或开发资源。
3. 模型调用方按已开放范围使用能力，并查看相关用量和监控。

## 踩坑提示

- 用户侧看不到资源时，不要只刷新页面，应同时核对地域、权限、配额、模板、规格和集群状态。
- 实例排队或失败时，先统一地域、可用区、集群、规格和时间范围，再比较监控或用量数据。
- 运营侧调整资源池、模板、额度或存储组件前，应确认影响范围、维护窗口和回退方式。
- 账号、角色、Key 和权限配置属于 Settings 子系统，On-Prem 概览只提供跳转和排查方向，不记录真实账号或凭据。

| 检查项 | 成功表现 | 异常时处理 |
| --- | --- | --- |
| 页面入口 | 可进入概览并看到目标操作入口 | 检查运营管理员权限和对应菜单是否已开放 |

## 常见问题

#### 概览中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的地域、可用区、集群、资源规格、模板、用量和监控入口。

**可能原因：**

- 筛选条件仍生效。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 重置筛选
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

#### 概览的操作入口不可用

**问题现象：**

新增、注册或维护入口不可见或不可点击。

**可能原因：**

- 当前角色权限不足。
- 页面处于只读状态。
- 依赖对象不满足条件。

**处理方式：**

1. 检查运营管理员权限
2. 核对页面提示
3. 先完成依赖对象配置。

#### 概览的必填项没有可选值

**问题现象：**

表单能打开，但下拉框为空。

**可能原因：**

- 候选对象未启用。
- 所属范围不一致。
- 当前账号不可见。

**处理方式：**

1. 到候选对象页面核对状态
2. 确认归属关系
3. 检查可见范围后刷新表单。

#### 概览操作后状态异常

**问题现象：**

提交后记录存在，但状态不是预期值。

**可能原因：**

- 连通性或校验失败。
- 关联对象异常。
- 后台处理尚未完成。

**处理方式：**

1. 查看页面提示和更新时间
2. 检查关联对象
3. 按状态阶段排查处理任务。

#### 下游页面无法使用概览

**问题现象：**

当前页状态正常，但下游页面无法选择或关联地域、可用区、集群、资源规格、模板、用量和监控入口。

**可能原因：**

- 可见范围不匹配。
- 对象未启用。
- 下游缓存未刷新。

**处理方式：**

1. 核对启用状态和归属
2. 检查角色可见范围
3. 刷新下游页面并重新选择。

## 注意事项

- 异构卡纳管入口页只用于判断阅读路径，具体创建、接入、扩容和排障步骤以对应功能页为准。
- 比较资源、配额或监控数据前，必须先统一地域、可用区、集群、租户和时间范围。
- 运营侧资源池配置会影响模型提供方或模型调用方可见资源，调整前应确认影响范围和回退方式。

- 排障材料中不要暴露真实账号、Token、AK/SK、API Key、租户、资源 ID、集群 ID、节点 IP、Endpoint、镜像仓库凭据、存储密钥或日志敏感片段。

## 后续操作

1. 运营管理员持续维护资源池、模板、配额和监控。
2. 模型提供方或模型调用方创建资源后及时查看用量、日志和监控。
3. 发布前定期检查文档截图、示例命令和敏感信息脱敏情况。
