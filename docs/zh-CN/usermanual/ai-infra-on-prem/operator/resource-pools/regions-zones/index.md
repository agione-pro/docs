# 地域/可用区

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员 |
| 导航路径 | On-Prem > 资源池 > 地域/可用区 |
| 页面路由 | `/powerone/resourcepool/region` |
| 管理对象 | 地域（Region）、可用区（Availability Zone）、地域关联组件、可用区下的集群资源 |

#### 新手理解

异构卡纳管资源池像一栋办公体系：

- **地域** 像城市，例如武汉、北京，用来区分大的资源所在范围。
- **可用区** 像城市里的办公区或楼层，用来继续划分具体承载资源的位置。
- **集群** 像办公区里的工位区，提供 CPU、GPU、内存、磁盘等实际算力。
- **作业** 像具体工作，必须被安排到某个集群上运行。
- **公共地域** 像开放式办公区，所有授权用户都可以共用。
- **专属地域** 像带门禁的独立办公室，只允许指定团队或租户使用。

所以第一次配置时，顺序不能反过来：先有地域，再有可用区，再把集群注册到可用区中，最后才能提交作业验证资源是否可用。

#### 术语表

| 术语 | 说明 |
| --- | --- |
| Harbor | 用于存储和分发作业所需镜像的容器镜像仓库；地域绑定镜像服务后，后续作业可从对应仓库拉取镜像。 |
| Endpoint | 服务访问入口，通常供平台或作业访问镜像、存储等组件。 |
| IP | 服务所在位置或访问地址，用于判断组件网络是否可达。 |
| 数据 Gateway | 地域级访问入口，供节点拉取镜像、作业访问对象存储。各地域的 Gateway 地址在镜像组件的数据 Gateway 行配置，也可在系统设置中集中管理。 |

#### 推荐操作顺序

先确认地域（Region）、可用区（Availability Zone）、地域关联组件、可用区下的集群资源的前置依赖，再按主要操作顺序处理，最后执行结果校验并进入后续页面。

#### 小白先看

先确认当前任务是否涉及地域（Region）、可用区（Availability Zone）、地域关联组件、可用区下的集群资源，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

开始配置前，请确认以下条件已满足：

1. 当前账号具备运营管理员权限，并能进入 `资源池 > 地域/可用区` 页面。
2. 至少已接入一个可用的镜像服务。镜像服务下拉为空时，优先到 `资源池 > 镜像组件` 检查组件是否已接入、已启用，以及当前账号是否有查看或绑定权限。
3. 如需在地域中使用对象存储、文件存储或块存储，需提前完成对应存储组件接入；下拉为空通常表示对应组件未接入、未启用或当前账号无权限。
4. 如后续要注册集群，需提前规划地域 ID、可用区 ID、显示名称和集群归属关系。
5. 如需配置数据 Gateway 入口，或到系统设置中集中管理各地域 Gateway，请确认当前账号也能进入 `系统 > 系统设置` 的 `用户服务访问` 分区。

## 页面说明

页面用于查看和处理地域（Region）、可用区（Availability Zone）、地域关联组件、可用区下的集群资源。

![地域/可用区](./images/manual-regions-zones.png)

页面由地域类型页签、地域名称搜索框、地域列表和地域详情区组成。进入页面后，系统默认展示公共地域列表，两个页签分别显示各自的地域数量；选中某个地域后，右侧展示该地域的组件绑定、可用区和集群资源。

截图中左侧为地域列表，列表底部是 `新增地域` 按钮，右侧为当前地域的可用区和集群资源卡片。

#### 地域类型页签与搜索

地域类型页签位于列表区顶部，用于切换地域范围。

| 项目 | 说明 |
| --- | --- |
| 地域类型页签 | 在 `公共地域` 与 `专属地域` 之间切换，每个页签括号内显示当前地域数量。公共地域可供全平台租户共享；专属地域用于限定使用范围。 |
| 名称搜索 | 在 `按名称搜索` 输入框中填写地域名称关键字可过滤当前列表。无匹配地域或专属地域列表为空时，列表区显示空态提示，`新增地域` 按钮仍可用。 |

#### 地域列表

左侧地域列表展示地域名称、状态徽标和 `...` 图标操作按钮。点击地域名称后，右侧详情区会刷新为当前地域的信息。

地域行的 `...` 操作菜单按当前状态提供动作：`正常` 状态提供 `编辑`、`禁用`；已禁用地域提供 `启用` 以恢复。地域没有删除动作。详情区头部同样提供选中地域的 `编辑`、`禁用`/`启用` 图标按钮，并展示地域 ID 与更新时间。

#### 地域详情

地域详情展示当前地域关联的资源能力，只有已绑定的组件类型才会渲染对应区块，未绑定的存储类型不显示区块：

- 镜像组件：展示数据 Gateway 行（网关地址与 `配置数据 Gateway 入口`），以及已绑定镜像服务卡片的仓库地址、用户名、镜像仓库数量、已启用公共镜像 tag 数量、描述和 `额度管理`、`健康检查`、`编辑` 动作。
- 存储组件：已启用的对象存储卡片展示服务端点、服务地域、`显示 Access Key` 控件、可用桶数量、参考桶上限、容量定价和 `配置限制`、`健康检查`、`编辑` 动作。文件存储和块存储区块仅在绑定对应组件后出现。
- 可用区：展示每个可用区的显示名称、ID、状态和更新时间。行右侧的动作图标随当前状态而变：`正常` 状态显示 `编辑`、`禁用`；已禁用状态显示 `启用`；`异常` 状态显示 `编辑`、`删除`。区块底部提供 `新增可用区` 按钮。

Endpoint 是服务访问入口，通常用于平台或作业访问对应组件；IP 是服务所在地址或访问地址，用于判断组件网络是否可达。

#### 可用区与集群资源

每个可用区行展示显示名称与可用区 ID、状态徽标和更新时间。行右侧的动作图标随当前状态而变：`正常` 状态显示 `编辑`、`禁用`；已禁用状态显示 `启用`；`异常` 状态显示 `编辑`、`删除`。

处于 `异常` 状态的可用区表示其下尚无可用集群。行内提示 `当前资源下没有可用集群`，展开区显示空态横幅 `当前没有集群，可用区无法使用，请关联集群`。按下一段所述关联集群后即可恢复使用。

关联集群时，展开可用区并使用展开区右侧的虚线占位卡片 `关联集群`（它是占位卡片，不是行内动作按钮）。点击 `关联集群` 不会打开已有集群选择器，而是携带当前地域和可用区参数（`…/resourcepool/cluster/create?regionId=<地域>&zoneId=<可用区>`）跳转到集群注册向导，用于在该可用区下**新注册集群**（KubeConfig 快速导入或手动录入连接信息）。

展开已有集群的可用区后，可查看该可用区下的集群资源使用情况。集群卡片通常展示以下信息：

- 集群名称。
- GPU、CPU、MEM、DISK 资源用量。
- 节点数量、作业数量和创建时间。

资源用量以“已用/总量”格式展示，用于快速判断某个可用区或集群是否存在资源瓶颈。数值为实时刷新，请勿将任一次快照数值当作容量基线。

#### 管理说明

- 地域列表的 `...` 操作菜单用于编辑、禁用地域，或对已禁用地域执行 `启用` 恢复；地域没有删除动作。详情区头部提供相同的 `编辑`、`禁用`/`启用` 入口。
- 右侧 `可用区` 区块的行图标随状态而变（`正常` = `编辑`/`禁用`，已禁用 = `启用`，`异常` = `编辑`/`删除`；地域无删除、可用区有删除），可通过展开区右侧的 `关联集群` 占位卡片进入集群注册向导，或展开查看可用区下的集群资源。
- 管理类动作可能影响新资源创建、新集群注册或新作业调度，执行前应确认地域、可用区、集群和作业依赖。

## 主要操作

### 新增地域

#### 适用场景

当平台需要接入新的算力资源区域，或需要按机房、城市、业务范围划分资源池时，新增地域。以下场景通常需要新增地域：

- 首次部署异构卡纳管资源池时，至少需要创建一个地域。
- 新增机房、新购算力或接入新的资源供应区域时，可按资源位置创建地域。
- 需要按租户、部门或业务线隔离资源时，可创建专属地域。

#### 配置前必读

新增地域前，先确认资源边界和组件选择逻辑：

- **地域** 用于划分大的资源边界，通常对应城市、机房、资源池或租户边界。
- **可用区** 必须归属于某个地域，用于在地域下继续区分机房区域、网络域、资源组或集群组。
- **镜像服务** 属于地域的关键依赖。没有可用镜像服务时，后续作业可能无法拉取运行镜像。
- **存储组件** 按业务需要开启。对象存储适合模型文件和数据集，文件存储适合共享目录，块存储适合独立磁盘卷。
- **公共地域** 适合共享资源池，例如共享测试资源池或公共训练资源池；**专属地域** 适合部门或租户独占生产算力资源池。
- 存储组件导航路径为 `资源池 > 对象存储组件`、`资源池 > 文件存储组件` 和 `资源池 > 块存储组件`。

#### 操作前确认

新增地域前必须已有可用镜像服务。没有镜像服务时，即使地域能创建，后续作业也可能无法拉取运行镜像。

建议先确认：

1. `资源池 > 镜像组件` 中已有可用镜像服务。
2. 当前账号具备绑定该镜像服务的权限。
3. 需要启用对象存储、文件存储或块存储时，对应组件已在 `资源池 > 对象存储组件`、`资源池 > 文件存储组件` 或 `资源池 > 块存储组件` 中完成接入并处于可用状态。
4. 地域 ID 已按长期规划确定。地域 ID 是资源边界标识，创建后不可修改。

#### 操作步骤

1. 进入 `On-Prem > 资源池 > 地域/可用区`。
2. 点击左侧地域列表底部的 **"新增地域"**，打开新增地域弹窗。
3. 在 `地域基础信息` 区块填写 `地域ID`，选择 `可见性策略`，并维护多语言 `显示名称`。
4. 在 `资源能力绑定` 区块选择必填的 `镜像服务（Harbor）`，并按需开启 `对象存储`、`文件存储` 或 `块存储`。

下图为新增地域表单。确认前请核对 `地域ID` 的格式要求、`公共地域` / `专属地域` 可见性策略，以及必选的镜像服务绑定。

![新增地域](./images/add-region.png)

5. 点击最终 **"确定"** 前，再次核对地域 ID、可见性策略、显示名称和资源能力绑定。
6. 如需放弃本次配置，点击 **"取消"** 关闭弹窗。

#### 新增地域字段说明

| 字段名称 | 是否必填 | 字段类型 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| 地域ID | 必填 | 文本 | `wuhan` | 地域唯一标识。长度 2–30；不能以 `-` 开头或结尾；只能包含小写字母、数字和连字符。创建后不可修改。 |
| 可见性策略 | 必填 | 单选 | `公共地域` | 控制地域是全平台共享还是专属范围可见。 |
| 显示名称 | 必填 | 多语言 | 中文简体 `武汉` / English `Wuhan` | 不同语言环境下展示的地域名称。需在 English / 中文简体 / Español 各页签分别维护。 |
| 镜像服务（Harbor） | 必填 | 下拉选择 | `image-xxx` | 地域绑定的镜像服务，后续作业依赖该服务拉取镜像。 |
| 对象存储 | 否 | 开关 / 下拉选择 | `关闭` | 按业务需要开启，用于非结构化数据、模型文件或数据集。 |
| 文件存储 | 否 | 开关 / 下拉选择 | `关闭` | 按业务需要开启，用于多节点共享文件系统。 |
| 块存储 | 否 | 开关 / 下拉选择 | `关闭` | 按业务需要开启，用于独立磁盘卷或高性能块设备。 |

#### 新增地域风险提示

- 地域 ID 创建后不可修改，提交前必须确认命名、区域含义和租户边界。
- 镜像服务不可用会影响作业拉取镜像，新增地域前应先确认镜像组件状态正常。
- 存储组件不是必选项，只在业务确实需要对应存储能力时开启。
- 公共地域会扩大资源可见范围，专属地域会限制资源范围；配置前应先确认租户或部门边界。

#### 新增地域提交校验

提交成功后，按以下方式检查配置是否生效：

1. 在左侧地域列表中确认新增地域已出现。
2. 确认地域状态为 `正常` 或符合预期状态。
3. 选中该地域，在右侧详情区确认镜像组件已显示。
4. 如开启了存储组件，确认对应存储组件出现在关联组件列表中。
5. 如后续要注册集群，进入集群注册页面确认该地域可被选择。

### 编辑地域

#### 适用场景

当地域的多语言显示名称或资源能力绑定需要调整，且地域 ID 与资源边界不变时，编辑地域。地域 ID 在编辑表单中保持只读。

#### 操作步骤

1. 进入 `On-Prem > 资源池 > 地域/可用区`。
2. 在左侧地域列表中选中目标地域，然后通过该行 **"..."** 操作菜单中的 **"编辑"**，或详情头部的 **"编辑"** 图标按钮打开编辑表单。
3. 按弹窗提供的字段修改 `地域基础信息` 区块：`地域ID` 只读，`可见性策略` 显示当前 `公共地域` / `专属地域` 选择，`显示名称` 位于 `多语言` 标签下并需在 English / 中文简体 / Español 各页签分别维护。
4. 在 `资源能力绑定` 区块调整页面允许编辑的绑定：`镜像服务（Harbor）` 标记为 `必选项`，`对象存储` 显示开关状态与已绑定组件，`文件存储` 与 `块存储` 整行置灰、开关关闭。
5. 点击 **"确定"** 前，确认变更不会误解绑正在使用的镜像或存储组件。
6. 如需放弃本次修改，点击 **"取消"** 关闭弹窗。
7. 返回列表和地域详情，核对更新后的名称、组件绑定和更新时间。

下面展示 **编辑地域** 弹窗。它沿用 **新增地域** 的 `地域基础信息` 与 `资源能力绑定` 两个区块，并按该地域的当前取值预填；图中已绑定组件的名称已做脱敏处理，实际取值以页面显示为准。

![编辑地域弹窗：只读的 `地域ID`、当前选中 `公共地域` 的 `可见性策略`、带 `多语言` 标签的 `显示名称`，以及 `镜像服务（Harbor）`、`对象存储`、`文件存储`、`块存储` 四行 `资源能力绑定`](./images/edit-region.png)

#### 结果校验

- 地域列表显示新的多语言名称，地域 ID 和所属层级保持不变。
- 地域详情中的镜像或存储组件绑定与提交内容一致。
- 后续集群注册页面仍能按预期选择该地域。

#### 注意事项

- 地域 ID 是资源边界标识，不能通过编辑操作修改；需要更换 ID 时应按变更流程评估新建地域及下游迁移。
- 解除组件绑定可能影响作业拉取镜像、挂载存储或后续资源创建，提交前先核对关联集群和作业。

### 禁用/启用地域

#### 适用场景

当地域需要暂时停止新资源使用时执行禁用，需要让已禁用地域重新提供服务时执行启用。当前状态为 `正常` 时，行 `...` 操作菜单和详情头部均显示 **"禁用"**；地域被禁用后，相同入口显示 **"启用"**。地域没有删除动作，禁用/启用是本页面可逆的生命周期控制。

#### 禁用地域

1. 进入 `On-Prem > 资源池 > 地域/可用区`，通过地域类型页签或名称搜索定位目标地域。
2. 打开目标地域行的 **"..."** 操作菜单选择 **"禁用"**，或点击详情头部的 **"禁用"** 图标按钮。
3. 阅读确认提示（例如 `确定禁用【武汉】吗?`），核对地域、关联可用区、集群和作业调度影响。
4. 确认影响范围后点击 **"确定"** 完成状态变更。
5. 刷新列表，检查地域状态和下游页面的可选范围。

#### 启用地域

1. 通过地域类型页签或名称搜索定位已禁用的地域；只有已禁用地域才会显示 **"启用"** 动作。
2. 打开地域行的 **"..."** 操作菜单选择 **"启用"**，或点击详情头部的 **"启用"** 图标按钮。
3. 阅读确认提示后刷新列表，确认地域恢复为 `正常` 状态。
4. 启用前请确认镜像服务、存储组件和下游集群状态正常，以便调度可正常恢复。

#### 结果校验

- 禁用后地域状态徽标相应变化；启用后地域恢复为 `正常` 状态。
- 变更后的地域仍可通过地域类型页签和名称搜索定位。
- 集群注册、作业调度或资源创建入口按地域状态执行相应限制。

#### 注意事项

- 禁用地域通常影响新集群注册、新资源创建和新作业调度，不等同于删除已有资源；执行前必须确认业务窗口。
- 当前 UI 中没有地域删除动作，禁用/启用是本页面可逆的生命周期控制。
- **"启用"** 动作仅在地域确实处于已禁用状态时出现，`正常` 状态显示的是 **"禁用"** 而非 **"启用"**。

### 配置数据 Gateway 入口

#### 适用场景

当地域下的镜像组件或对象存储组件需要指定访问地址，以便节点拉取镜像、作业通过 Gateway 访问对象存储时，配置数据 Gateway 入口。该入口位于地域详情的 `关联组件` 区（镜像组件的数据 Gateway 行）。

#### 操作步骤

1. 进入 `On-Prem > 资源池 > 地域/可用区`，选中目标地域。
2. 在 `关联组件` 区打开镜像组件卡片的 **"配置数据 Gateway 入口"**，弹窗标题带地域名（例如 `配置数据 Gateway 入口 - 武汉`）。
3. 填写 `镜像 Gateway 地址` 与 `对象存储 Gateway 地址`。地址支持域名、`IP:端口` 或带协议地址；未填写协议时默认使用 HTTPS，填写 `http://` 或 `https://` 后按填写内容请求。
4. 点击 **"保存"** 生效，或 **"取消"** 放弃。

#### 跨页入口

弹窗提供 **"前往系统设置管理全部 Gateway"** 链接，点击后跳转到 `On-Prem > 系统 > 系统设置` 的 `用户服务访问` 分区，集中管理各地域的 Gateway 地址表、Gateway 对接密钥、入口使用域名解析开关、外层 Nginx 地址与默认端口开放策略。

#### 注意事项

- Gateway 入口地址与环境相关且可能为内网地址，请勿在本文档或截图中记录真实内网 IP、主机名或端口。
- 修改 Gateway 入口会影响该地域下作业拉取镜像和访问对象存储，保存前先确认新地址可达。

### 新增可用区

#### 适用场景

当一个地域下需要承载新的集群，或需要按机房机架、网络域、资源组继续拆分资源时，新增可用区。以下场景通常需要新增可用区：

- 同一地域下有多套集群，需要按集群组划分资源。
- 同一城市或机房中存在不同机房区域、楼层、网络域或机架区域。
- 需要做网络隔离、故障隔离或资源分组，避免所有集群混在同一可用区下。

#### 操作前确认

新增可用区前必须先创建并选中目标地域。可用区不能脱离地域存在，归属选错会影响后续集群注册和作业调度。

建议先确认：

1. 目标地域已创建，且状态为 `正常` 或符合当前操作预期。
2. 已在左侧地域列表中选中目标地域。
3. 可用区 ID 已按地域规划确定，建议包含地域前缀和序号，例如 `wuhan-1`、`wuhan-gpu-1`。
4. 可用区 ID 创建后不可修改。

#### 操作步骤

1. 在左侧地域列表中选择目标地域。
2. 在右侧 `可用区` 区块点击 **"新增可用区"**，打开可用区弹窗。
3. 确认 `地域` 字段：该字段只读并自动带入当前选中地域，核对即为目标地域。
4. 填写 `可用区ID`。
5. 在多语言 Tab（English / 中文简体 / Español）中分别填写 `显示名称`。
6. 按需填写描述，例如地理位置、机房编号或业务用途。

下图为新增可用区表单。所属地域为只读带入项；确认前填写可用区 ID、各语言页签的显示名称，并按需补充描述。

![新增可用区](./images/add-availability-zone.png)

7. 点击最终 **"确定"** 前，再次核对地域、可用区 ID、显示名称和描述。

| --- | --- | --- | --- | --- |

| 可用区ID | 必填 | 文本 | `wuhan-1` | 可用区唯一标识。校验允许字母、数字和中文（长度 2–30；不能以 `_`、`-`、`@`、`.` 或空格开头结尾），但为与更严格的地域 ID 规则保持一致，强烈建议使用小写字母、数字和连字符组合，如 `wuhan-1`、`wuhan-gpu-1`。创建后不可修改。 |

#### 新增可用区风险提示

- 新增可用区前必须先选择目标地域，不要在错误地域下创建可用区。
- 可用区 ID 创建后不可修改，建议带地域前缀和序号，避免多个地域下出现难以区分的名称。
- 可用区创建后还不能直接运行作业，需要继续在该可用区下注册集群。

#### 新增可用区提交校验

提交成功后，按以下方式检查配置是否生效：

1. 在目标地域详情中确认新增可用区已出现。
2. 确认可用区 ID、显示名称和描述符合预期。
3. 确认可用区状态为 `正常` 或符合预期状态。
4. 进入集群注册页面，确认该地域下可以选择新增的可用区。

4. 点击 **"确定"** 前，确认可用区仍归属于正确地域，且名称变更不会影响识别或运维交接。
5. 如需放弃本次修改，点击 **"取消"** 关闭弹窗。
6. 返回可用区列表，核对名称、描述、状态和更新时间。

### 禁用/启用可用区

#### 适用场景

当某个可用区需要暂时停止新集群注册或新作业使用时执行禁用，需要让已禁用可用区重新可用时执行启用。行右侧图标随当前状态而变：`正常` 状态显示 `编辑`、`禁用`；可用区被禁用后显示 `启用`；`异常` 状态（其下尚无可用集群）显示 `编辑`、`删除`。与地域不同，可用区因此还提供 `删除` 动作用于永久移除，暂停与恢复请用 `禁用`/`启用`，确需下线时才用 `删除`。

#### 禁用可用区

1. 进入 `On-Prem > 资源池 > 地域/可用区`，选中目标地域。
2. 在右侧 `可用区` 区块找到目标可用区，点击该行的 **"禁用"** 按钮。
3. 阅读确认提示，核对可用区下的集群、节点、作业和存储影响。
4. 确认影响范围后点击确认按钮完成状态变更。
5. 刷新可用区列表，检查状态以及集群注册和作业调度页面的可选范围。

#### 启用可用区

1. 选中所属地域并定位已禁用的可用区；只有已禁用可用区才会显示 **"启用"** 动作。
2. 在该可用区行选择 **"启用"**。
3. 阅读确认提示后刷新列表，确认可用区恢复为 `正常` 状态。
4. 启用前请确认可用区下集群健康、资源上报和存储配置正常，以便调度可正常恢复。

#### 结果校验

- 禁用后可用区状态徽标相应变化；启用后可用区恢复为 `正常` 状态。
- 目标可用区仍可在其所属地域下定位。
- 集群注册或作业调度页面按可用区状态限制新业务使用。

#### 注意事项

- 禁用可用区会影响其下集群的新注册或新作业调度；先确认已有作业、节点和存储的处理安排。
- **"启用"** 动作仅在可用区确实处于已禁用状态时出现，`正常` 状态行内显示的是 **"禁用"** 而非 **"启用"**。
- 与地域不同，可用区提供 **"删除"** 动作，删除会永久移除该可用区；执行前请确认无集群或作业仍依赖它，仅需临时暂停与恢复时应用 `禁用`/`启用`。

## 踩坑提示

- **配置顺序**：必须先创建地域，再创建可用区，最后才能在对应可用区下注册集群。
- **镜像服务**：新增地域时应绑定可用镜像服务，否则后续作业可能无法正常拉取镜像。
- **存储组件**：对象存储、文件存储和块存储按需开启。未接入对应组件时，不应在地域中强行启用。
- **公共地域**：适合全平台共享资源池，例如共享测试资源池或公共训练资源池。
- **专属地域**：适合限定租户、限定业务或隔离资源池，例如部门独占 GPU 资源池。
- **新增影响**：新增地域或可用区可能影响资源池归属、集群纳管、调度范围和容量展示。
- **禁用/启用/删除影响**：禁用地域或可用区可能影响新作业调度、新集群注册或新资源创建；已禁用对象可通过其行的 **"启用"** 动作恢复。地域没有删除动作，可用区额外提供 **"删除"** 用于永久移除。生产环境执行任何生命周期动作前，请先确认业务窗口和影响范围。
- **资源观察**：可用区下的集群资源用量用于快速判断容量，不替代集群节点监控；排查资源瓶颈时应进入集群或节点详情页。
- **多语言显示名称**：显示名称需在 English / 中文简体 / Español 各语言页签分别维护，填全平台提供的每个页签，避免不同语言环境下名称为空或语义不一致。
- **关联集群**：`关联集群` 卡片用于在该可用区下新注册集群，不能把已有集群改挂到该可用区；调整集群归属请在集群管理页处理。

## 常见问题

#### 编辑地域后名称或绑定未更新

**问题现象：**

保存后列表仍显示旧名称，或地域详情没有出现新的组件绑定。

**可能原因：**

- 修改未通过最终确认。
- 页面状态或数据更新时间尚未刷新。
- 组件本身不可用或当前账号无权查看。

**处理方式：**

1. 重新打开地域编辑入口，核对字段和页面提示。
2. 刷新列表并重新选中地域，检查更新时间。
3. 到对应组件页面确认组件状态和当前账号可见范围。

#### 如何恢复已禁用的地域

**问题现象：**

维护某个地域时先做了禁用，之后需要让它重新对外提供服务。

**可能原因：**

- `正常` 状态的地域显示 **"禁用"** 而非 **"启用"**，所以只有地域真正处于已禁用状态时才会出现恢复入口。
- 该地域处于 `失效` 等其他状态，而不是"已禁用"状态。

**处理方式：**

1. 先确认目标地域当前的状态徽标，**"启用"** 动作仅对已禁用地域出现。
2. 通过地域行 `...` 菜单或详情头部的 **"启用"** 入口恢复。地域没有删除动作，行菜单在 `正常`（显示禁用）与 `已禁用`（显示启用）之间切换。
3. 若你预期为已禁用的地域仍不显示 **"启用"**，请核对运营管理员权限与地域可见范围，并与平台管理员确认该地域是否处于 `失效` 等其他状态。

#### 编辑可用区后归属显示不正确

**问题现象：**

编辑完成后，可用区仍显示在错误地域，或集群注册页面找不到该可用区。

**可能原因：**

- 创建可用区时选中的是其他地域，归属从创建之初就是错误的（编辑表单中地域只读，不会因编辑改变归属）。
- 地域名称搜索框或地域类型页签隐藏了目标记录。
- 可用区状态或所属地域不可用于后续注册。

**处理方式：**

1. 返回地域详情，确认可用区的父地域和状态。
2. 清空地域名称搜索框、切换地域类型页签后重新加载可用区列表。
3. 到集群注册页面核对地域、可用区和可用状态。

#### 如何恢复或移除已禁用的可用区

**问题现象：**

禁用某个可用区后，需要让它重新可用，或彻底下线删除。

**可能原因：**

- `正常` 状态的可用区显示 **"禁用"** 而非 **"启用"**，所以只有可用区真正处于已禁用状态时才会出现恢复入口。
- 不确定应该"禁用"（可逆暂停）还是"删除"（永久移除）。

**处理方式：**

1. 查看可用区当前的状态徽标，**"启用"** 动作仅对已禁用可用区出现。
2. 要恢复该可用区，使用行内的 **"启用"**；要永久移除，使用行右侧的 **"删除"** 图标——与地域不同，可用区提供删除动作，且该图标按当前状态出现（例如其下尚无可用集群的 `异常` 行）。
3. 删除前确认无集群或作业仍依赖该可用区；仅需临时暂停时应用 `禁用`（之后可再 `启用`）。若权限或所属地域状态异常导致动作不出现，请核对运营管理员权限、所属地域状态和可用区可见范围。

#### 地域/可用区中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的地域（Region）、可用区（Availability Zone）、地域关联组件、可用区下的集群资源。

**可能原因：**

- `按名称搜索` 输入框仍有关键字，或当前停留在错误的地域类型页签。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 清空 `按名称搜索` 输入框，并在 `公共地域` / `专属地域` 页签间切换查看
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

## 注意事项

- 地域 ID 和可用区 ID 都是资源边界标识，建议按长期规划命名，避免临时命名。
- 地域 ID 仅允许小写字母、数字和连字符；可用区 ID 推荐同样使用小写字母、数字和连字符组合。
- 地域 ID 和可用区 ID 创建后不可修改，提交前应确认命名、归属和显示名称。
- 新增地域或可用区可能影响资源池归属、集群纳管、调度范围和容量展示，生产配置前应先确认影响范围。
- 错误地域 ID 或可用区 ID 可能导致后续资源绑定、授权或调度异常。
- 本页的最终动作是 `确定`（新增地域/可用区、禁用确认）、`保存`（数据 Gateway 入口弹窗）与 `删除`（`异常` 状态的可用区），都会写入真实配置，属高风险最终动作；执行前确认范围与影响。
- 截图前应检查页面中是否暴露真实机房编码、内网地址、集群 ID、资源池 ID、账号、密钥、Token、证书、私钥、访问密钥或内部测试参数。
- 当前账号需要具备查看和绑定镜像、存储、地域、可用区的权限；下拉为空时应先排查组件状态和账号权限。

## 后续操作

完成本章节后，请继续检查或执行以下事项：

1. 进入 `资源池 > 集群管理` 注册集群，并确认新增地域和可用区可被选择。
2. 在地域详情中确认镜像服务状态正常，Endpoint 和 IP 信息符合预期。
3. 如启用了存储组件，确认对象存储、文件存储或块存储组件状态正常。
4. 为目标集群关联规格和必要存储。
5. 提交测试作业，确认镜像可拉取、资源可调度、存储可挂载、作业可正常运行。
