# 对象存储组件

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员 |
| 导航路径 | AI基础设施(On-Prem) > 资源池 > 对象存储组件 |
| 页面路由 | `/powerone/resourcepool/storage` |
| 管理对象 | 服务商类型、存储源名称、服务端点或服务地域、访问凭据、桶与容量额度、容量定价、描述和健康状态 |

#### 新手理解

- **对象存储** 像一个按桶组织的文件仓库，适合保存模型权重、数据集、压缩包和运行产物。
- **Bucket** 像对象存储的顶层容器，用户侧创建桶后才能组织对象。
- **Endpoint** 是访问入口，平台、集群或作业需要通过它访问对象存储。
- **AK/SK** 是访问凭据，属于敏感信息，不应出现在截图、文档或工单中。

#### 术语表

| 术语 | 说明 |
| --- | --- |
| MinIO | 常见的兼容 S3 协议的对象存储实现。 |
| S3 | 对象存储的 API 协议或兼容接口。 |
| Bucket | 对象存储中用于组织对象的顶层容器。 |

#### 推荐操作顺序

先确认服务商类型、访问凭据、服务端点或服务地域、存储源名称，以及额度与定价规划的前置依赖，再按主要操作顺序处理，最后执行结果校验并进入后续页面。

#### 小白先看

先确认当前任务是否涉及服务商类型、访问凭据、服务端点或服务地域、存储源名称和额度与定价，再按照推荐顺序操作。页面字段或状态与预期不符时，先回到前置对象页核对依赖，不要跳过结果校验直接进入下游流程。

## 前提条件

1. 对象存储服务已部署完成，并能从平台管理侧和目标集群访问。
2. 已准备服务端点或服务地域、访问协议、认证方式、访问凭据、桶与容量规划、容量定价和关联地域。
3. 已确认 Bucket 命名、租户隔离、权限边界和数据保留策略。
4. 当前账号具备运营管理员资源池管理权限。

## 页面说明

页面用于维护已接入的对象存储源：服务商类型、存储源名称、服务端点或服务地域、访问凭据、桶与容量额度、容量定价、描述和健康状态。

![对象存储组件](./images/manual-object-storage.png)

对象以卡片形式展示，每张卡片显示 `服务端点`（含 `复制服务端点`）、`服务地域`、掩码后的 `Access Key`（含 `显示 Access Key` 与 `复制 Access Key`）、`可用桶数量 N 个`、`参考桶上限 N 个`、按 credits/GiB/小时 表示的容量定价、`创建时间：…` 与可用区标签。页头提供 `全部云服务商` / `兼容S3` / `AWS S3` / `阿里云 OSS` / `华为云 OBS` 页签，可在搜索框按名称、服务端点或地域检索并点击 `查询`，右侧另有 `注册`。

## 主要操作

### 注册对象存储组件

#### 适用场景

当需要接入新的 MinIO、S3 兼容存储或其他对象存储服务，并让地域、用户侧 Bucket 或作业读写对象路径使用该存储能力时，注册存储组件。正文中的对象存储组件仍指本页面管理的对象存储接入对象。

#### 操作步骤

1. 进入 `AI基础设施(On-Prem) > 资源池 > 对象存储组件`，点击 **"注册"** 打开 `注册 S3 存储源` 弹窗。
2. 选择服务商卡片：`兼容S3`、`AWS S3`、`阿里云 OSS`、`华为云 OBS`。每张卡片会列出该账号所需的权限码，可一键复制。
3. 填写 `Access Key *` 与 `Secret Key *`，可用 `显示密钥` 查看明文。
4. 填写地址或地域：`兼容S3`、`AWS S3`、`阿里云 OSS` 填写服务端点；`华为云 OBS` 将该字段替换为服务地域，候选由 `加载地域` 返回。
5. 填写 `存储源名称 *` 与 `描述`，点击最终 **"账号预检"** 提交。注册弹窗内没有额度字段，桶数量、容量与定价在注册后通过卡片配置。
6. 提交前再次核对服务商、服务端点或服务地域、Access Key 与存储源名称。

下图展示注册对象存储组件表单，用于配置对象存储访问方式和连接参数。

![注册对象存储组件](./images/object-storage-register.png)

#### 结果校验

- 提交成功后，存储源以卡片形式出现，卡片显示状态、`服务端点` 或 `服务地域` 行、`可用桶数量 N 个`、`参考桶上限 N 个`、`容量定价` 与 `创建时间：…`。
- 卡片同时提供本页其余操作用的四个入口：额度入口、`健康检查`、`编辑`、`删除`。
- 额度与定价不属于注册环节。请在卡片的额度入口配置，桶数量上限、容量上限与容量定价会在同一弹窗一次 `保存`。

#### 注意事项

- 注册弹窗底部只有 `取消` 与 `账号预检`；编辑弹窗的最终按钮是 `保存修改`，两者是不同入口、行为也不同。
- `华为云 OBS` 形态用 `服务地域 *` 取代服务端点字段，其候选在凭据填写完整后由 `加载地域` 返回。
- 填入的账号需已具备所选服务商卡片列出的权限码。

### 配置额度与定价

卡片上的 **"配置 <存储源名称> 的限制"** 打开同一个弹窗，内含 `默认额度`、`租户额度`、`定价策略` 三个页签；额度与定价一次提交。

#### 适用场景

当需要设置每租户默认桶数量与容量上限、为单个租户单独配置，或调整按小时计费的容量单价时，使用该弹窗。

#### 操作步骤

1. 在目标卡片点击额度入口打开弹窗，弹窗顶部显示存储源名称与其服务端点。
2. 在 `默认额度` 页签设置桶数量上限与容量上限及其单位。某项额度没有单独配置租户时按该默认值生效。
3. 在 `租户额度` 页签选择租户，填写桶数量与容量上限（留空表示不限制），点击 **"添加"**。`已配置` 列表给出 `租户名称`、`桶数量`、`容量上限`、`已分配容量`、`更新时间`，行内可 `编辑` 或 `恢复默认`。
4. 在 `定价策略` 页签设置以 credits / GiB / 小时 表示的容量定价。页签显示当前版本号与历史调价记录表，历史项区分 `当前生效` 与 `历史版本`。留空表示不计费。
5. 点击 **"保存"**。页面注明修改容量定价后与额度限制一起提交；点击 **"取消"** 放弃。

#### 结果校验

- 卡片显示新的容量定价，`可用桶数量` 与 `参考桶上限` 按默认额度呈现。
- `定价策略` 页签的当前版本递增，旧价格进入历史表。

#### 注意事项

- 定价与额度共用一次保存，即使只想改价格，被改动过的额度字段也会一并写入。
- `已分配容量` 是该租户在此存储源上活动桶的容量配额之和，不是实际文件用量。
- 调低桶数量或容量上限可能影响已创建的桶，变更前确认业务窗口。

### 编辑对象存储组件

#### 适用场景

当对象存储源的服务端点或服务地域、名称、描述、凭据需要调整时，编辑该存储源。

#### 操作步骤

1. 在目标卡片点击 **"编辑 <存储源名称>"**，打开 `编辑 S3 存储源` 弹窗。
2. 凭据字段留空表示保留原凭据，填写新值则替换。
3. 修改服务端点或服务地域、`存储源名称` 与 `描述`。
4. 点击 **"保存修改"** 提交，或点击 **"取消"** 放弃。

#### 结果校验

- 卡片显示新的名称、服务端点或服务地域与描述。

#### 注意事项

- 编辑弹窗的最终按钮是 `保存修改`，与注册弹窗的 `账号预检` 不同。
- 健康检查与额度定价弹窗是独立入口，不属于本次编辑。

## 参数速查表

| 字段名称 | 是否必填 | 字段类型 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| 服务商类型 | 必填 | 卡片选择 | `兼容S3` | 取值为 `兼容S3`、`AWS S3`、`阿里云 OSS`、`华为云 OBS`。该选择决定弹窗要求服务端点还是服务地域。 |
| Access Key | 必填 | 凭据 / 敏感文本 | `<ACCESS_KEY_ID>` | 对象存储访问 AK。只在系统表单中填写，不写入文档、截图或工单。 |
| Secret Key | 必填 | 凭据 / 敏感文本 | `<ACCESS_KEY_SECRET>` | 对象存储访问 SK。属于敏感凭据，不写入文档、截图或工单。 |
| 服务端点 | 条件必填 | 地址 / 路径 | `<BASE_URL>` | 用于 `兼容S3`、`AWS S3`、`阿里云 OSS`。文档中不写真实端点。 |
| 服务地域 | 条件必填 | 下拉 / 枚举 | `<REGION_ID>` | `华为云 OBS` 用它替换服务端点字段，候选在凭据填写完成后由 `加载地域` 返回。 |

| 描述 | 否 | 多行文本 | `示例说明` | 组件用途、边界或维护说明。只记录非敏感说明。 |
| 桶数量上限 / 容量上限 | 否 | 数值 / 容量 | `10` / `5 GiB` | 在「配置额度与定价」弹窗设置，注册弹窗内没有该字段。 |
| 容量定价 | 否 | 数值 / 计价 | `<PRICE>` | 在 `定价策略` 页签设置，与额度共用一次保存。留空表示不计费。 |
| 操作 | 系统生成 | 操作入口 | `编辑` | 卡片提供额度与定价入口、健康检查入口、编辑入口与删除入口。健康检查与 `删除` 属于高风险动作。 |

## 踩坑提示

- 注册存储组件会影响地域对象存储能力、用户侧 Bucket 创建、作业读写对象路径和数据访问范围。
- 服务端点、服务地域、证书、AK/SK、Bucket 策略或额度配置错误，可能导致作业无法读写对象存储。
- AK/SK、Token、内部连接串、生产 Bucket 路径属于敏感信息，不能写入文档、截图或工单。
- `保存 / Save`、`提交 / Submit`、`确定 / OK` 属于高风险最终动作。
- 不写真实 Endpoint、内网地址、AK/SK、Token、Bucket 名称、生产对象路径、集群 ID、资源池 ID 或内部测试参数。

## 常见问题

#### 对象存储组件中找不到目标对象

**问题现象：**

页面可进入，但没有看到预期的对象存储源、服务商卡片、服务端点或服务地域、额度与定价入口。

**可能原因：**

- 筛选条件仍生效。
- 对象属于其他范围。
- 前置配置未完成。

**处理方式：**

1. 重置筛选
2. 核对所属地域或租户
3. 返回前置页面确认对象状态。

#### 对象存储组件的操作入口不可用

**问题现象：**

新增、注册或维护入口不可见或不可点击。

**可能原因：**

- 当前角色权限不足。
- 页面处于只读状态。
- 依赖对象不满足条件。

**处理方式：**

1. 检查运营管理员权限
2. 核对页面提示
3. 先完成依赖对象配置。

#### 对象存储组件的必填项没有可选值

**问题现象：**

表单能打开，但下拉框为空。

**可能原因：**

- 候选对象未启用。
- 所属范围不一致。
- 当前账号不可见。

**处理方式：**

1. 到候选对象页面核对状态
2. 确认归属关系
3. 检查可见范围后刷新表单。

#### 对象存储组件操作后状态异常

**问题现象：**

提交后记录存在，但状态不是预期值。

**可能原因：**

- 连通性或校验失败。
- 关联对象异常。
- 后台处理尚未完成。

**处理方式：**

1. 查看页面提示和更新时间
2. 检查关联对象
3. 按状态阶段排查处理任务。

#### 下游页面无法使用对象存储组件

**问题现象：**

当前页状态正常，但下游页面无法选择对象存储源、其桶与容量额度或目标租户适用的定价。

**可能原因：**

- 可见范围不匹配。
- 对象未启用。
- 下游缓存未刷新。

**处理方式：**

1. 核对启用状态和归属
2. 检查角色可见范围
3. 刷新下游页面并重新选择。

## 注意事项

- 注册存储组件会影响地域对象存储能力、用户侧 Bucket 创建、作业读写对象路径和数据访问范围。
- 不要截图或记录真实 Endpoint、内网地址、AK/SK、Token、内部连接串、生产 Bucket 名称和生产对象路径。
- 删除、禁用或替换对象存储组件前，应确认数据迁移、备份、地域绑定和依赖作业。

- 不写真实 Endpoint、内网地址、AK/SK、Token、Bucket 名称、生产对象路径、集群 ID、资源池 ID 或内部测试参数。
