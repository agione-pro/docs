## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 模型提供方&用户 |
| 导航路径 | 账务 > 我的账务 > 月度账单 |
| 页面路由 | `/billing/my/account/transactions/monthly-summary` |
| 管理对象 | 跨月账期消费趋势、所选账期摘要、扣费记录及消费分布 |

月度账单用于选择账期、阅读消费与充值摘要，并从消费服务或支出归属两类分组查看分布，通过本期流水入口继续核对记录。

#### 新手理解

月度账单像按月份整理的收支摘要：上方趋势比较多个账期，下方内容对应所选账期；没有统计结果不等于整月金额为零。

#### 术语速查

| 术语 | 说明 |
| --- | --- |
| 账期 | 当前查看的月度范围，可选择当前月及前 12 个月。 |
| 账期消费趋势 | 跨多个账期的消费柱状图，不是单月内的每日趋势。 |
| 本账期消费 | 所选账期的消费摘要，以 credits 展示。 |
| 净变动 | 所选账期的余额净变化，与消费和充值分别展示。 |
| 扣费记录 | 摘要中单独展示的扣费记录数量。 |
| 分组视角 | 先选择消费服务或支出归属，再选择该组下的具体维度。 |

## 前提条件

1. 当前账号可以进入 `账务 > 我的账务 > 月度账单`。
2. 已确定需要核对的账期，区分当前账期与历史月份。
3. 如需核对单笔来源，可继续查看 [流水明细](../transactions/)。

## 页面说明

英文左侧分组名为 `Billing`。页面提供 `账期` 选择，`刷新数据` 入口随当前数据状态显示。`账期消费趋势` 是跨月柱状图，提示为 `点击柱形查看该账期账单明细`。

当前账期提示 `本账期账单仍在累计，最终结算项将在下月1日生成`。这是页面的账期说明，不是已完成生成或结算的结果提示。

| 区域 | 说明 |
| --- | --- |
| 账期 | 选择当前月或前 12 个月中的目标月份。 |
| 刷新数据与更新状态 | 根据页面当前状态显示刷新入口或更新时间；`正在统计数据` 表示统计尚未就绪。 |
| 账期消费趋势 | 以 credits 展示跨账期消费；可按图中提示点击柱形查看对应账期。 |
| 账期累计提示 | 说明当前账期仍在累计及最终结算项的生成日期。 |
| 账期摘要 | 本账期消费、充值、净变动、扣费记录。 |
| 本期流水入口 | `本期流水` 和 `查看本期流水明细` 用于继续核对流水。 |
| 按消费服务 | 第一层分组，下含 `模型` 和 `AI Infra`。 |
| 按支出归属 | 第一层分组，下含 `项目` 和 `成员`。 |
| 分布区域 | 展示当前分组视角；空态为 `暂无分布数据`。 |
| 统计空态 | 所选账期没有统计结果时显示 `暂无统计结果`，不应改读为金额 `0`。 |

## 主要操作

### 选择账期并阅读摘要

1. 进入 `账务 > 我的账务 > 月度账单`。
2. 在 `账期` 中选择目标月份，可选范围为当前月及前 12 个月。
3. 留意页面的数据更新状态；显示 `刷新数据` 入口时按需使用。`正在统计数据` 表示统计尚在进行，不将未展示的摘要填为金额 `0`。
4. 阅读跨月 `账期消费趋势`；按 `点击柱形查看该账期账单明细` 的提示选择柱形后，再核对当前账期选择。
5. 有摘要时分别阅读 `本账期消费`、`充值`、`净变动` 和 `扣费记录`；若显示 `暂无统计结果`，按空态阅读，不填写为整月金额 `0`。

### 按两层分组查看分布

1. 确认当前账期与需要核对的月份一致。
2. 选择第一层 `按消费服务`，再选择其下的 `模型` 或 `AI Infra`。
3. 查看所选消费服务维度的分布；显示 `暂无分布数据` 时，按当前视角的空态阅读。
4. 选择第一层 `按支出归属`，再选择其下的 `项目` 或 `成员`。
5. 阅读切换后的分布区域；空态只说明当前视角没有可展示的分布，不代表系统没有该维度。

### 继续核对本期流水

1. 在有账期摘要的页面定位 `本期流水` 或 `查看本期流水明细`。
2. 使用对应入口继续查看流水，或进入 [流水明细](../transactions/)。
3. 进入流水页面后核对日期范围、交易类型和收支类型，不预设入口已经替你设置全部筛选条件。

## 踩坑提示

- 跨期趋势与所选账期统计是不同区域，不能把跨月柱状图理解为单月每日消费。
- 当前账期仍在累计的提示不是最终结算完成证明；不要将刷新操作读作生成结算项。
- 选择 `2025-11` 的示例显示 `暂无统计结果`，而不是全月金额 `0`；统计空态也不能说明跨期趋势没有历史数据。
- `暂无分布数据` 只描述当前分布区域，不表示模型、AI Infra、项目或成员维度不存在。

| 检查项 | 成功表现 | 异常时处理 |
| --- | --- | --- |
| 账期范围 | 选择器显示目标月份，可选当前月及前 12 个月。 | 重新核对账期选择；页面提供 `刷新数据` 时再按需使用。 |
| 跨期趋势 | 显示 `账期消费趋势` 及点击柱形查看账期的提示。 | 按提示定位目标柱形，选择后核对账期，不按日趋势解释。 |
| 摘要或空态 | 有统计时显示四项摘要；无统计时显示 `暂无统计结果`。 | 区分“有数值”与“无统计结果”，不把空态填成 `0`。 |
| 分组层级 | `按消费服务` 下为模型、AI Infra；`按支出归属` 下为项目、成员。 | 先核对第一层分组，再核对组内维度和当前空态。 |
| 流水入口 | 有摘要时可定位 `本期流水` 和 `查看本期流水明细`。 | 区分统计空态与摘要区域；也可从菜单进入流水明细。 |

## 常见问题

#### 为什么页面提示账单仍在累计？

**问题现象：** 页面显示 `本账期账单仍在累计，最终结算项将在下月1日生成`。

**可能原因：** 这是当前账期的累计说明，文字说明了最终结算项将在下月 1 日生成。

**处理方式：** 按当前账期摘要阅读，不将提示本身或刷新动作当作结算已经完成的证据。

#### 暂无统计结果是否代表整月消费为零？

**问题现象：** 所选账期的统计区域显示 `暂无统计结果`。

**可能原因：** 当前展示的是统计空态，不是消费金额 `0`；上方跨期趋势属于另一个展示区域。

**处理方式：** 先核对账期，需要继续查询时使用 `刷新数据` 或流水明细；不要把空结果替换成零金额结论。

#### 为什么找不到四个并列的分组入口？

**问题现象：** 页面先显示 `按消费服务` 和 `按支出归属`，没有四个并列的模型、AI Infra、项目、成员入口。

**可能原因：** 分组采用两层结构，模型和 AI Infra 属于消费服务，项目和成员属于支出归属。

**处理方式：** 先选择第一层分组，再选择组内维度；若分布区域显示 `暂无分布数据`，按当前视角空态阅读。

## 注意事项

- 不公开真实客户信息、账号邮箱、私人账务金额或历史趋势数值；公开示例使用 `0` 或占位符，配图使用空结果。
- 消费、充值、净变动和扣费记录应分别阅读，不从空态推导金额公式、结算结果或高费用的业务原因。
- 月度账单用于账期汇总核对；单笔记录继续查看流水明细，不将当前账期摘要当作最终结算凭证。
