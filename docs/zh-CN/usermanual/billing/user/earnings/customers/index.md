# 客户总览

::: info 文档信息
版本：v2.1
更新日期：2026-11-05
:::

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 模型提供方 |
| 导航路径 | 账务 > Provider 收益 > 客户总览 |
| 页面路由 | `/billing/provider/customers` |
| 管理对象 | 客户身份、客户标签和所选账期的客户收益信息 |

`客户总览` 用于按账期、综合关键词和客户标签定位客户，核对本账期收益、占比、客户加入时间和账期最近收益，并提供行内 `详情` 与 `管理标签` 入口。

#### 新手理解

客户总览像 Provider 的客户收益索引：顶部看客户统计，下方按条件找客户，再核对每位客户在所选账期的收益。

#### 术语速查

| 术语 | 说明 |
| --- | --- |
| 账期 | 本次查看客户收益的月份范围。 |
| 本账期收益 | 客户在所选账期内贡献的收益。 |
| Top 1 客户 | 所选账期内收益贡献最高的客户。 |
| Top 5 占比 | Top 5 客户的收益占比。 |
| 内置标签 | 平台提供并锁定、按当前语言展示的标签。 |
| 自定义标签 | 本 Provider 私有的标签。 |

## 前提条件

1. 已登录模型提供方账号，并能进入 `Provider 收益 > 客户总览`。
2. 已确定要核对的账期和客户查询范围。
3. 准备提交自定义标签前，已确认标签名称、颜色及所属 Provider。

## 主要操作

### 查询客户收益

1. 进入 `账务 > Provider 收益 > 客户总览`。
2. 选择需要查看的账期。
3. 在 `搜索租户、管理员、邮箱、电话或租户ID` 输入框中填写关键词，按回车查询。
4. 按需选择一个或多个客户标签；多选按 OR 匹配，不要求客户同时具有全部已选标签。
5. 账期和标签选择后条件自动生效；需要重新查询关键词时，修改输入内容并按回车。
6. 查看客户表格。出现 `暂无数据` 时，先核对账期、关键词和已选标签，不将空表格理解为全平台没有客户。

### 核对客户信息与详情入口

1. 在同一账期内定位目标客户，核对 `租户信息`、`管理员信息` 和 `标签`；需要复制标识时使用对应信息处的复制入口。
2. 分别阅读 `本账期收益`、`占比` 和 `客户加入时间`。
3. 查看 `账期最近收益`；若当前窗口宽度下有列未显示，横向滚动表格查看。
4. 需要继续查看该客户时，核对目标行后使用 `操作` 列中的 `详情` 入口。

### 刷新客户统计

1. 确认当前账期，并阅读顶部客户总数、账期新增、Top 1 客户和 Top 5 占比。
2. 需要更新统计时，点击 `刷新统计`。
3. 核对页面显示的统计更新时间与统计值，分别阅读顶部卡片和客户表格，不用关键词空查询结果推算卡片数值。

### 查看标签管理与填写区域

1. 点击 `管理标签`，打开 `标签管理` 弹窗。
2. 查看 `平台内置` 的五个标签：`VIP`、`高潜`、`试用`、`待跟进`、`流失风险`，均标注为 `内置·锁定`。
3. 查看 `自定义标签` 区域；图示状态为 `还没有自定义标签，下面新建一个。`。自定义标签为本 Provider 私有。
4. 如需准备自定义标签，在 `新标签名` 中填写不超过 16 字的名称，并选择颜色。
5. `新建标签` 是提交入口；点击前确认名称、颜色与 Provider 范围。不需要变更时，不要提交。
6. 点击 `关闭` 退出弹窗。

## 踩坑提示

- 标签多选按 OR 匹配，不是要求客户同时具有全部已选标签。
- 关键词查询后的 `暂无数据` 只表示当前查询结果为空，不代表全平台没有客户，也不能据此认定顶部 KPI 全为 0。
- 表格有横向内容；当前视窗未显示 `账期最近收益` 等列，不等于页面缺少这些字段。
- `每客户最多 5 个` 限制的是单个客户应用的标签数量，不是自定义标签库总量。
- 内置标签锁定；自定义标签为本 Provider 私有，不是 Operator 私有标签或双方共享的自定义标签库。

## 结果校验

| 检查项 | 成功表现 | 异常时处理 |
| --- | --- | --- |
| 查询条件 | 账期、关键词和已选标签与本次核对目标一致；空结果显示 `暂无数据` | 核对并调整对应条件；关键词修改后按回车重新查询。 |
| 表格字段 | 能辨认租户、管理员、标签、收益、占比、加入时间、最近收益和操作列 | 横向滚动查看右侧列，不只按当前视窗判断字段是否存在。 |
| 统计读取 | 顶部客户统计、统计更新时间和下方客户查询结果分别核对 | 不将空表格直接换算为客户总数或收益统计为 0。 |
| 标签管理 | 弹窗显示五个锁定的内置标签、Provider 私有说明及自定义标签区域 | 对照内置与自定义区域分别核对；无需变更时点击 `关闭`。 |

## 常见问题

#### 为什么客户表格为空，不能据此判断所有客户统计为 0？

**问题现象：**

输入关键词后，客户表格显示 `暂无数据`。

**可能原因：**

当前关键词查询没有匹配记录；表格显示的是当前条件下的查询结果，不是全平台客户总量。

**处理方式：**

核对账期、关键词和已选标签；调整关键词后按回车重新查询，并将顶部统计卡片与客户表格分开阅读。

#### 为什么内置标签标为锁定？

**问题现象：**

标签管理中的五个内置标签均显示 `内置·锁定`。

**可能原因：**

弹窗说明内置标签由平台提供并锁定，按当前语言展示；自定义标签属于另一独立区域，为本 Provider 私有。

**处理方式：**

按内置标签的当前语言名称识别分类；需要准备自定义标签时使用自定义区域，名称不超过 16 字，提交前确认 Provider 范围。

## 注意事项

- 不公开真实客户身份、账号、邮箱、电话或账务数据；共享核对信息时只提供接收方获授权且确有必要的内容。
- `新建标签` 是变更提交入口。打开弹窗或填写名称、颜色不等于标签创建完成；无变更需求时使用 `关闭`。
- 客户收益核对需保持账期一致；不要根据关键词或标签查询后的空表格推断 KPI 统计范围或收益占比分母。
- 行内 `详情` 属于目标客户的查看入口，使用前先确认客户身份，避免混淆不同客户记录。
