# 财务账户

::: info 文档信息
版本：v2.1
更新日期：2026-11-05

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员 |
| 导航路径 | 账务 > 运营账务 > 财务账户 |
| 页面路由 | `/billing/admin/financial-accounts` |
| 管理对象 | 平台清算账户、平台收益账户、实时余额、账期统计和账户流水 |

本页用于在两个平台账户之间切换，查看实时余额、所选账期的清算或收益统计，并核对账户流水。

#### 新手理解

清算账户像资金中转池，收益账户像平台留存收益的归集账本；实时余额与按账期统计的数字需要分开阅读。

#### 术语速查

| 术语 | 说明 |
| --- | --- |
| 平台清算账户 | 客户消费的 credits 实时入账暂存；结算执行时支付租户应得，平台留存部分划转至收益账户。 |
| 平台收益账户 | 系统完成入账确认后，留存手续费入账；本页用于查看收益归集和统计趋势。 |
| 实际余额 | 标记为“实时”的账户余额，不是所选账期的净流入。 |
| 账期视图 | 按所选账期展示的清算或收益统计。 |
| 账户流水 | 用于核对资金流向、交易对象、业务上下文和引用信息的记录。 |

## 前提条件

1. 当前账号能够访问 `账务 > 运营账务 > 财务账户`。
2. 已明确需要核对的平台账户和账期。
3. 对照结算单或月结总览时，先确认比较的是实时余额还是账期统计。

## 页面说明

菜单名称为 `财务账户`，页面内容标题为 `平台账务账户`。页面通过 `平台清算账户`、`平台收益账户` 两个按钮页签切换内容，不是先选账户列表再进入账户详情。

| 区域 | 说明 |
| --- | --- |
| 账户页签 | 在平台清算账户与平台收益账户之间切换。 |
| 实际余额 | 以 credits 显示，并带有“实时”标记。 |
| 账期视图 | 包含账期选择和“刷新”；清算账户显示“清算处理”，收益账户显示“收益”。 |
| 清算处理 | 显示“待结算给 Provider”和“待转平台留存”。 |
| 收益 | 显示“待入账”“留存手续费”“PowerOne 自营”和“统计收入合计”。 |
| 收益账户趋势 | 显示“近 12 期”的留存手续费、PowerOne 自营、统计收入合计，以及“累计统计收益”。 |
| 账户流水 | 包含方向、来源系统筛选以及流水表格和分页。 |

流水列依次为 `时间`、`资金流向`、`交易对象`、`业务上下文`、`引用信息`、`金额`、`操作`。筛选条件是 `方向`（入账、出账）与 `来源系统`；交易对象和引用信息是结果内容，不是租户或流水号筛选框。

## 主要操作

### 查看平台清算账户

1. 进入 `账务 > 运营账务 > 财务账户`。
2. 点击 `平台清算账户`，阅读资金中转池说明。
3. 查看带“实时”标记的 `实际余额`。
4. 在 `账期视图` 选择目标 `账期`，点击 `刷新`。
5. 核对 `待结算给 Provider` 与 `待转平台留存`，再查看同页的账户流水。

### 查看平台收益账户

1. 点击 `平台收益账户`。
2. 查看实时 `实际余额`，并阅读留存手续费入账说明。
3. 选择目标 `账期`，点击 `刷新`。
4. 分别读取 `待入账`、`留存手续费`、`PowerOne 自营` 和 `统计收入合计`。
5. 查看 `收益账户趋势` 的 `近 12 期` 图例及 `累计统计收益`，不要将统计收益直接当作实时账户余额。

### 查询并核对账户流水

1. 保持在目标账户页签，确认账户流水区域显示的账期。
2. 按需选择 `方向`（`入账` 或 `出账`）和 `来源系统`。
3. 逐列核对时间、资金流向、交易对象、业务上下文、引用信息和金额；有多页时使用分页查看。
4. 有记录且 `操作` 列出现 `详情` 时，点击打开该笔流水详情，按实际展示内容与列表核对资金及业务线索。
5. 完成只读核对后关闭详情；查看详情不代表完成结算、入账确认或任何资金提交。

![账户流水空结果表格](./images/financial-accounts-transactions.png)

图示为选择入账方向后的流水空结果表格，显示“暂无数据”及当前可见的列名；该图仅展示表格元素。`金额` 列位于当前可读视区之外，需横向滚动表格查看，完整七列定义见参数速查表。

## 踩坑提示

- `实际余额` 标记为“实时”，`账期视图` 则标明所选账期；不能将两者直接解释为同一范围。
- `统计收入合计`、`累计统计收益` 与实时余额是不同展示项，不应互相替代。
- 入账方向下的“暂无数据”只描述当前账户、账期及筛选条件下的流水结果，不表示账户没有余额或其他方向没有流水。

## 结果校验

| 检查项 | 成功表现 | 异常时处理 |
| --- | --- | --- |
| 账户选择 | 页面显示所选平台账户名称及对应说明 | 核对当前点击的账户页签。 |
| 统计范围 | 实际余额标记“实时”，账期视图显示目标账期 | 分开读取两种口径，核对账期选择。 |
| 流水范围 | 能核对当前账期、方向和来源系统，表格显示记录或“暂无数据” | 先核对已选条件，不从空结果推导全账户结论。 |
| 流水详情 | 有记录时可通过“详情”核对该笔流水 | 返回列表核对目标行，不将只读查看当作资金操作完成。 |

## 常见问题

#### 为什么不能用账期统计直接解释实时余额？

**问题现象：** 页面同时显示“实际余额”和“账期视图”。

**可能原因：** 前者明确标记“实时”，后者按所选账期展示；收益页还单列统计收入和累计统计收益。

**处理方式：** 先区分账户、实时余额和统计范围，再使用对应账期的流水核对，不以统计值替代余额。

#### 选择入账后显示“暂无数据”说明什么？

**问题现象：** 流水表格保留列名，但没有记录。

**可能原因：** 当前显示的是所选账户、账期、方向与来源系统条件下的空结果。

**处理方式：** 核对当前条件；不要将该结果扩展为其他方向或整个账户均无流水。

## 注意事项

- 本页的操作说明以查看和核对为范围，不以查看详情代替入账确认或结算执行。
- 对账时分别确认账户、账期、资金方向和业务引用，不仅凭单个汇总值下结论。
- 不在公开文档中写入真实账务金额、账户标识或客户数据；示例金额统一使用 0。
