# 快速接入

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员 |
| 导航路径 | AI基础设施 > On-Cloud > 接入工作台 > 快速接入 |
| 页面路由 | `/infrahub/op/workbanch/quick` |
| 管理对象 | 云平台、平台授权、账号、资源池和资源池授权的完成进度 |

#### 新手理解

快速接入像一张五步检查单。它不替代各配置页，而是告诉运营管理员当前接入链路完成到哪一步，以及下一步应该去哪里。

#### 术语表

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 接入状态 | Access Status | 整条接入链路的总体状态。 |
| 完成进度 | Completion Progress | 已完成步骤数与总步骤数。 |
| 接入步骤 | Access Step | 云平台、授权、账号和资源池等流程节点。 |

#### 推荐操作顺序

从第一项未完成步骤开始处理，完成后回到快速接入刷新；全部完成后打开接入总览继续检查部署资产和授权状态。

#### 小白先看

| 场景 | 先做 | 不要直接做 |
| --- | --- | --- |
| 第一次进入页面 | 查看现有对象、状态和可用操作 | 直接修改未知对象 |
| 准备变更配置 | 核对上游依赖、影响范围和目标对象 | 跳过依赖和影响检查 |
| 操作完成 | 按结果校验表复核当前页和下游页面 | 只看成功提示不复核下游 |
| 页面出现异常 | 记录脱敏对象、时间和页面提示 | 反复提交或写入真实凭据 |

## 前提条件

1. 当前账号具备 `快速接入` 页面或流程所需权限。
2. 当前账号可访问五个接入步骤对应的对象页。
3. 补齐步骤前已确认目标平台、租户、业务和资源范围。

## 主要操作

### 查看接入进度

1. 进入 `AI基础设施 > On-Cloud > 接入工作台 > 快速接入`。
2. 查看总体状态和完成进度。
3. 从云平台到资源池授权依次核对每一步状态。

![快速接入进度](./images/quick-start-list.png)

上图展示快速接入进度。重点核对目标对象、当前状态、字段和操作入口。

### 补齐接入步骤

1. 定位第一项未完成步骤。
2. 进入对应的云平台、账号、资源池或授权页完成配置。
3. 返回快速接入并刷新，确认步骤变为完成。

### 打开接入总览

1. 确认五个步骤均为完成。
2. 点击 **"查看接入总览"**。
3. 继续核对部署资产和授权状态。

## 踩坑提示

- 不要跳过上游依赖检查：当前账号可访问五个接入步骤对应的对象页。
- 配置变更前先确认影响：补齐步骤前已确认目标平台、租户、业务和资源范围。
- 页面成功提示不等于下游已同步，操作后必须按结果校验表复核。
- 示例凭据只使用 `<API_KEY>`、`<PERSONAL_KEY>`、`<ACCESS_KEY_ID>`、`<ACCESS_KEY_SECRET>`、`<BASE_URL>` 和 `<ENDPOINT_PATH>`。

## 常见问题

#### 快速接入中找不到目标对象

**问题现象：**

页面列表或选择器中没有预期对象。

**可能原因：**

- 查询条件仍在生效，目标对象被过滤。
- 上游对象未启用，或当前角色没有可见权限。

**处理方式：**

1. 清除筛选并刷新页面。
2. 回到前置对象核对：当前账号可访问五个接入步骤对应的对象页。
3. 确认当前角色和数据范围后重新定位目标对象。

#### 快速接入操作入口不可用

**问题现象：**

预期按钮、菜单或状态开关不可用。

**可能原因：**

- 当前账号缺少对应操作权限。
- 目标对象状态、引用关系或前置条件不允许执行该操作。

**处理方式：**

1. 核对按钮对应的权限和目标对象当前状态。
2. 检查页面提示的引用关系和前置条件。
3. 解除阻断条件后刷新页面，再执行一次。

#### 快速接入修改后下游未生效

**问题现象：**

页面提示成功，但后续页面仍显示旧状态。

**可能原因：**

- 关联页面存在缓存或同步延迟。
- 当前页与下游页使用了不同角色、租户或数据范围。

**处理方式：**

1. 等待同步完成并刷新当前页和下游页。
2. 确认两页使用相同角色、租户和对象范围。
3. 仍不一致时回到责任对象核对保存结果。

#### 快速接入数据与其他页面不一致

**问题现象：**

当前页面的数量或状态与关联页面不同。

**可能原因：**

- 两个页面的筛选条件、统计口径或更新时间不同。
- 对象变更仍在同步，或当前角色的数据权限不同。

**处理方式：**

1. 统一两页的筛选条件和统计口径。
2. 核对各页面更新时间并等待同步。
3. 按对象详情逐项比较，不只对比汇总数量。

#### 快速接入操作失败如何排查

**问题现象：**

提交后页面提示失败或状态长时间不变化。

**可能原因：**

- 必填字段、字段组合或对象状态不满足提交条件。
- 上游依赖失效、网络请求失败，或同一操作已在处理中。

**处理方式：**

1. 记录脱敏后的对象、时间和完整页面提示。
2. 核对必填字段、对象状态和上游依赖。
3. 确认没有进行中的相同任务后再重试一次。

## 注意事项

- 补齐步骤前已确认目标平台、租户、业务和资源范围。
- 文档、截图、工单和聊天记录中不得写入真实账号、凭据、内部地址或客户数据。
- 涉及授权、部署、删除、发布、启停或计费的变更，应保留可审计记录并准备恢复方案。

## 后续操作

1. 进入接入总览查看接入底座、运营资源清单和授权状态。
2. 对未完成步骤，进入云平台、资源池、账号或授权页面补齐配置。
3. 接入链路确认后，再进入模型库、推理框架、推理镜像或策略页面检查部署资产。
