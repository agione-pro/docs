# 从零开始部署云上模型服务

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员、模型提供方 |
| 导航路径 | 用户手册 > 多平台调度 > 从零开始部署云上模型服务 |
| 页面路由 | 不适用（文档导航页） |
| 管理对象 | 云平台接入到模型部署校验的跨角色主链路 |

#### 新手理解

这条流程像搭建一条完整的部署跑道。运营管理员先准备云资源、授权、模型和运行环境，模型提供方再选择模型与规格创建部署，最后在我的部署中检查服务是否可用。

#### 术语表

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 部署点 | Deployment Target | 模型服务实际运行的云平台、地域和资源组合。 |
| 主备路由 | Primary/Backup Route | 在主要部署点异常时切换到备用部署点的调度关系。 |
| 服务状态 | Service Status | 部署创建后用于判断服务是否已就绪的状态。 |

#### 推荐操作顺序

严格按接入、授权、资产、策略、账号、快速部署、结果校验的顺序执行；任一步校验失败时先回到对应对象页处理，不跳过依赖继续提交。

#### 小白先看

| 场景 | 先做 | 不要直接做 |

## 前提条件

1. 当前账号具备 `从零开始部署云上模型服务` 页面或流程所需权限。
2. 目标云平台、地域、模型能力、资源规格和责任人已确认。
3. 部署资源、调用费用、授权范围和回滚方案已完成评估。

## 主要操作

### 完成云资源接入

1. 运营管理员添加云平台和云账号，凭据只使用安全输入框维护。
2. 启用目标资源池，并在接入总览确认云平台、账号和资源池均可见。
3. 凭据示例只使用 `<ACCESS_KEY_ID>` 和 `<ACCESS_KEY_SECRET>`。

### 完成授权与资产准备

1. 完成租户-云平台授权和业务-资源池授权。
2. 准备模型、推理框架、推理镜像和框架版本。
3. 创建策略并核对主备路由和健康探测规则。

### 创建并校验模型部署

1. 模型提供方在接入管理中确认可用云账号。
2. 在快速部署中选择模型、部署地域和资源规格，核对推荐结果与费用后点击 **"部署"**。
3. 在我的部署中核对状态、事件和服务信息；异常时按失败阶段回到账号、授权、资产或策略页排查。

## 常见问题

#### 从零开始部署云上模型服务中找不到目标对象

**问题现象：**

页面列表或选择器中没有预期对象。

**可能原因：**

- 查询条件仍在生效，目标对象被过滤。
- 上游对象未启用，或当前角色没有可见权限。

**处理方式：**

1. 清除筛选并刷新页面。
2. 回到前置对象核对：目标云平台、地域、模型能力、资源规格和责任人已确认。
3. 确认当前角色和数据范围后重新定位目标对象。

#### 从零开始部署云上模型服务操作入口不可用

**问题现象：**

预期按钮、菜单或状态开关不可用。

**可能原因：**

- 当前账号缺少对应操作权限。
- 目标对象状态、引用关系或前置条件不允许执行该操作。

**处理方式：**

1. 核对按钮对应的权限和目标对象当前状态。
2. 检查页面提示的引用关系和前置条件。
3. 解除阻断条件后刷新页面，再执行一次。

#### 从零开始部署云上模型服务修改后下游未生效

**问题现象：**

页面提示成功，但后续页面仍显示旧状态。

**可能原因：**

- 关联页面存在缓存或同步延迟。
- 当前页与下游页使用了不同角色、租户或数据范围。

**处理方式：**

1. 等待同步完成并刷新当前页和下游页。
2. 确认两页使用相同角色、租户和对象范围。
3. 仍不一致时回到责任对象核对保存结果。

#### 从零开始部署云上模型服务数据与其他页面不一致

**问题现象：**

当前页面的数量或状态与关联页面不同。

**可能原因：**

- 两个页面的筛选条件、统计口径或更新时间不同。
- 对象变更仍在同步，或当前角色的数据权限不同。

**处理方式：**

1. 统一两页的筛选条件和统计口径。
2. 核对各页面更新时间并等待同步。
3. 按对象详情逐项比较，不只对比汇总数量。

#### 从零开始部署云上模型服务操作失败如何排查

**问题现象：**

提交后页面提示失败或状态长时间不变化。

**可能原因：**

- 必填字段、字段组合或对象状态不满足提交条件。
- 上游依赖失效、网络请求失败，或同一操作已在处理中。

**处理方式：**

1. 记录脱敏后的对象、时间和完整页面提示。
2. 核对必填字段、对象状态和上游依赖。
3. 确认没有进行中的相同任务后再重试一次。

## 后续操作

1. 模型提供方进入我的部署，持续查看服务状态、Endpoint、事件和监控。
2. 如需发布模型，进入 `模型及AI服务 > 创作空间 > 我的部署` 的 `On-Cloud` 列表，选择发布区域后跳转到 [我的模型](../../../model-services/user/studio/my-models/) 的发布模型页面。
3. 使用脱敏调用示例验证模型输出、延迟和错误码。
4. 运营管理员定期复核云账号授权、资源池容量、调度策略和部署资产版本。
5. 发现费用或容量异常时，结合多平台调度用量、模型及AI服务调用记录和云厂商账单交叉核对。
