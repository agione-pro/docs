# 配置账号与权限闭环

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员 |
| 导航路径 | 设置 > 运营管理 |
| 页面路由 | 当前页面入口 |
| 管理对象 | 配置账号与权限闭环 |

#### 新手理解

账号与权限配置像给新成员办理门禁：先确认成员属于哪个租户，再决定他拿哪类角色权限，之后检查他能不能进入目标页面，最后在操作日志里确认配置记录。

#### 术语速查

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 租户 | Tenant | 成员和权限归属的业务主体。；先确认租户和管理员。 |
| 成员 | Member | 需要访问平台的账号。；添加前确认邮箱、手机号和身份。 |
| 角色 | Role | 成员可访问菜单和操作的权限集合。；先建角色再分配成员。 |
| Key | Key | 接口调用使用的访问凭证。；按用途拆分并设置有效期。 |
| 操作日志 | Operation log | 记录成员、角色和配置变更的审计线索。；变更后用它复核。 |

## 前提条件

1. 当前账号具备设置运营管理员权限。
2. 已明确目标租户、目标成员、需要授权的角色和业务用途。
3. 若涉及接口调用，已确认需要 Model API Key 还是 System API AK/SK。
4. 若涉及新增成员、角色授权、Key 创建、登录策略变更、删除、重置或 Key 轮换，已确认审批依据和回退方案。

## 踩坑提示

- 先确认租户再分配角色，错误租户下的授权不会解决目标页面不可见问题。
- 新增成员、角色授权、Key 创建和登录策略变更都属于高风险配置链路，应先确认审批依据和影响范围。
- 高权限角色不要长期给临时成员保留，授权完成后应按最小权限复核。
- Key 创建后只代表凭据生成成功，调用方仍需替换配置并确认额度、过期时间和接口权限。
- 操作日志缺失时不要立即重复操作，先放宽时间范围并确认日志权限。

## 常见问题

#### 成员已经添加但仍看不到菜单怎么办？

**问题现象：**

成员可以登录，但目标菜单没有显示。

**可能原因：**

成员没有绑定正确角色，角色权限不包含目标菜单，或成员处于错误租户上下文。

**处理方式：**

先核对成员租户和角色绑定；再进入角色页确认菜单权限；必要时重新登录刷新权限。

#### Key 创建后仍调用失败怎么办？

**问题现象：**

调用方已拿到 Key，但接口仍返回鉴权或额度相关错误。

**可能原因：**

Key 类型不匹配、权限范围不足、额度不足、Key 已过期，或调用方仍使用旧凭证。

**处理方式：**

核对 Key 类型、状态、过期时间、权限范围和额度限制；让调用方确认配置已替换；仍失败时结合操作日志和业务接口错误继续排查。

#### 配置账号与权限闭环变更后为什么没有更新？

**问题现象：**

操作完成后，列表或详情仍显示旧值。

**可能原因：**

缓存或同步存在延迟，操作未真正提交，或查看的不是同一个对象。

**处理方式：**

核对成功提示、对象标识和更新时间，刷新列表并重新打开详情；必要时到操作日志确认记录。

#### 如何安全导出或截图配置账号与权限闭环页面？

**问题现象：**

需要把页面信息用于排障、审计或交付。

**可能原因：**

页面可能包含账号、邮箱、IP、内部路径、租户标识、Key 或金额等敏感信息。

**处理方式：**

只保留必要字段和操作上下文，使用浅灰小颗粒马赛克覆盖敏感文字，不外发完整凭证或内部地址。

#### 配置账号与权限闭环页面出现异常数据怎么办？

**问题现象：**

字段、状态、统计或关联对象与预期不一致。

**可能原因：**

页面范围、时间条件、角色权限或上游配置不一致。

**处理方式：**

记录脱敏后的对象、时间和结果，先核对页面入口及筛选条件，再查看关联页面和操作日志。

## 注意事项

- 高权限角色应按最小权限原则配置，不要长期给临时成员保留管理员权限。
- 新增成员、角色授权、Key 创建、登录策略变更、删除成员、重置密码和轮换 Key 前，应确认通知、窗口和回退方式。
- 工单和截图中不要暴露完整邮箱、手机号、Key、AK/SK、Token、内部地址、租户 ID 或成员 ID。
