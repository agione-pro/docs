# 快速入门

## 功能概述

| 项目 | 内容 |
| --- | --- |
| 适用角色 | 运营管理员 |
| 导航路径 | 设置 > 运营管理 |
| 页面路由 | 当前页面入口 |
| 管理对象 | 快速入门 |

#### 新手理解

设置像平台的控制面板：先确认自己是谁，再确认有哪些成员、每个人有什么角色，之后再配置租户规则、登录安全和 API 流控。新手不要直接改配置，应先判断问题属于个人账号、成员权限、租户规则、登录安全还是接口流控。

#### 术语速查

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 账号信息 | Term | 当前登录账号的身份和安全联系方式。；关键操作前先确认账号上下文。 |
| Key | Key | 调用模型或系统接口的访问凭证。；按用途拆分并定期轮换。 |
| 成员 | Member | 可登录或协作的账号。；登录失败时先查成员状态。 |
| 角色 | Role | 一组菜单和操作权限。；看不到菜单时核对角色绑定。 |
| 租户 | Tenant | 平台里的业务主体。；操作前确认租户和管理员。 |

## 前提条件

1. 当前账号已具备设置菜单权限。
2. 已明确本次要处理的是个人账号、成员角色、租户、日志、系统配置还是 API 流控。
3. 涉及删除、重置、授权、发布、回滚、导出或登录策略变更前，已确认影响范围和回退方式。
4. 对外沟通前，确认账号、邮箱、手机号、Key、AK/SK、Token 和内部地址已脱敏。

本页用于查看和处理快速入门相关对象，页面入口、筛选区、列表或配置区以当前角色实际可见内容为准。

## 主要操作

### 选择设置入口

1. 进入 `设置 > 运营管理`。
2. 根据页面筛选项定位目标快速入门。
3. 查看列表、详情或状态字段，并结合页面上下文确认目标对象。
4. 结果异常时清除筛选条件，重新打开目标页面核对。

![选择设置入口](../operator/personal/profile/images/manual-settings-operator-profile.png)

截图保留左侧导航和完整功能区，顶部菜单已隐藏；请重点查看快速入门页面的字段、按钮和操作位置。

**结果校验：** 列表、详情和状态字段能够显示目标对象，且信息相互一致。

**注意事项：** 只使用当前页面实际展示的字段和入口，不根据其他角色页面推断能力。

**常见问题：** 如果入口不可见、按钮置灰或结果未更新，先检查当前账号权限、筛选条件、对象状态和页面刷新时间。

## 踩坑提示

- 设置快速入门只帮助选择路径，不替代具体页面的字段说明和操作步骤。
- 成员看不到菜单时不要只看账号状态，还要核对租户上下文、角色绑定和菜单权限。
- Key、登录配置、角色权限和 API 流控都可能影响访问结果，排查时要按对象分层确认。

## 常见问题

#### 不知道先看用户侧还是运营侧怎么办？

**问题现象：**

进入设置后，不确定该看用户侧设置还是运营管理员设置。

**可能原因：**

用户侧更关注当前账号和租户内可见对象，运营侧更关注平台级成员、租户、系统策略和 API 流控。

**处理方式：**

处理自己的账号、Key、项目和额度，先看用户侧；处理成员、角色、租户、登录配置或流控规则，进入运营管理员侧。

#### 看不到某个设置菜单怎么办？

**问题现象：**

左侧导航没有目标菜单，或页面打开后没有操作按钮。

**可能原因：**

当前账号缺少对应角色权限，或当前租户上下文不包含该对象。

**处理方式：**

先确认当前账号和租户；再让管理员核对角色授权；必要时重新登录后刷新菜单。

#### 快速入门变更后为什么没有更新？

**问题现象：**

操作完成后，列表或详情仍显示旧值。

**可能原因：**

缓存或同步存在延迟，操作未真正提交，或查看的不是同一个对象。

**处理方式：**

核对成功提示、对象标识和更新时间，刷新列表并重新打开详情；必要时到操作日志确认记录。

#### 如何安全导出或截图快速入门页面？

**问题现象：**

需要把页面信息用于排障、审计或交付。

**可能原因：**

页面可能包含账号、邮箱、IP、内部路径、租户标识、Key 或金额等敏感信息。

**处理方式：**

只保留必要字段和操作上下文，使用浅灰小颗粒马赛克覆盖敏感文字，不外发完整凭证或内部地址。

#### 快速入门页面出现异常数据怎么办？

**问题现象：**

字段、状态、统计或关联对象与预期不一致。

**可能原因：**

页面范围、时间条件、角色权限或上游配置不一致。

**处理方式：**

记录脱敏后的对象、时间和结果，先核对页面入口及筛选条件，再查看关联页面和操作日志。

## 注意事项

- 快速入门只帮助选择路径，不替代具体功能页字段说明。
- 账号、角色、租户和系统配置会互相影响，排查时要先统一对象范围。
- 登录配置、流控发布、成员删除和 Key 轮换属于高风险操作，应先确认影响范围。
