# 技术实践

本章节提供各类 AI 编码工具与 AI 应用平台接入 AGIOne 的集成指南。

## AI 编码工具接入

在主流 AI 编码工具中将 AGIOne 配置为模型提供商，涵盖 IDE 插件、命令行工具与桌面客户端。

| 工具 | 说明 |
|------|------|
| [Cherry Studio](./cherry-studio/) | 在 Cherry Studio 中添加 AGIOne 作为模型提供商 |
| [Claude Code](./claude-code/) | 在 VS Code 中使用 Claude Code 接入 AGIOne 模型 |
| [Claude Code Plugin](./claude-code-plugin/) | 使用 Claude Code 插件接入 AGIOne 模型 |
| [Cline](./cline/) | 使用 Cline 在 VSCode 中访问 AGIOne 模型 |
| [Codex](./codex/) | 安装 Codex 并使用 AGIOne 作为模型提供商 |
| [Codex Desktop (CC Switch)](./codex-desktop/) | 使用 CC Switch 配置 Codex Desktop 接入 AGIOne 模型 |
| [Crush](./crush/) | 安装 Crush 并使用 AGIOne 作为模型提供商 |
| [Cursor](./cursor/) | 安装 Cursor 并使用 AGIOne 作为模型提供商 |
| [DeepSeek Harness](./deepseek-harness/) | 在 DeepSeek Harness 中添加 AGIOne 作为模型提供商 |
| [Kilo Code](./kilo-code/) | 将 AGIOne 集成到 Kilo Code |
| [Open Code](./open-code/) | 将 AGIOne 集成到 Open Code |
| [Roo Code](./roo-code/) | 将 AGIOne 集成到 Roo Code |

## AI 应用与工作流

在应用编排与工作流平台中调用 AGIOne 模型，完成具体的业务自动化任务。

| 平台 | 说明 |
|------|------|
| [Dify](./dify/) | 使用 Dify 构建定时天气信息检索工作流 |
| [n8n](./n8n/) | 使用 n8n 构建定时天气邮件工作流 |
| [Open WebUI](./open-webui/) | 使用 Open WebUI 创建模型对话 |
| [OpenClaw](./openclaw/) | 将 AGIOne 集成到 OpenClaw |
