# API Reference

This section collects AGIOne interfaces for developers. Choose the credential and API family that matches your task.

## System API

Use a System API AK/SK pair for the AGIOne system and management endpoints explicitly documented for this credential family. See [System API](./system-api/).

| Document | Description |
|------|------|
| [System API](./system-api/) | Scope, credentials, and available endpoints |
| [Authentication and signing](./system-api/authentication) | AK/SK request headers, HMAC-SHA256 signing, and curl examples |
| [Get caller roles](./system-api/endpoints) | Roles held by the authenticated caller identity |

## Protocol Compatibility

Protocol-compatible proxy services and integration specifications. See [Protocol Compatibility](./protocol-compatibility/).

| Protocol / Platform | Description |
|------|------|
| [Doubao Compatible Proxy API](./protocol-compatibility/doubao/) | Proxy service providing Doubao-compatible video generation tasks and Volcengine Ark-style asset management interfaces |

## Model API (OpenAPI)

AGIOne native model invocation interface specifications using a Model API Key. See [Model API (OpenAPI)](./openapi/).

| Document | Description |
|------|------|
| [Model API (OpenAPI)](./openapi/) | Authentication, Base URL rules, error codes, and rate limit conventions |
